# NxEF Draw 이벤트 PRD
**버전**: v1.0
**작성일**: 2024-02-10
**작성자**: 서비스기획팀
**상태**: 확정

---

## 1. 프로덕트 목적

### a. 문제 정의

일부 인기 상품(한정판 스니커즈 등)은 일반 선착순 판매 방식으로 운영 시 소수의 반응 속도 빠른 고객이 독점하는 문제가 있다. 이는 구매 기회를 원했으나 얻지 못한 고객의 불만을 야기하고, 재판매(리셀) 목적의 구매를 조장할 수 있다.

Draw(추첨) 방식을 도입하여 모든 응모 고객에게 공평한 구매 기회를 제공하고, 응모 자체를 하나의 이벤트로 만들어 플랫폼 방문을 유도한다.

### b. 제안

특정 상품을 Draw 방식으로만 판매하는 기능을 도입한다. 일정 기간 응모를 받은 후 무작위 추첨으로 구매자를 선정하고, 당첨자에게만 결제 기회를 제공한다.

---

## 2. 성공 지표

- **Draw 상품 응모 건수 평균 100건 이상**
- **Draw 이벤트로 인한 홈 방문자 수 평균 30% 이상 증가** (이벤트 기간 내)
- **당첨자 구매 완료율 90% 이상** (당첨 후 24시간 내 결제 기준)

---

## 3. Draw 운영 방식

### 3-1. 기본 방식

- **응모 기간**: 관리자가 설정 (예: 3일간 응모)
- **추첨 방식**: 응모자 중 무작위(랜덤) 추첨
- **당첨 인원**: 판매 가능 수량과 동일 (단일 재고 상품이므로 보통 1명)
- **결제 시간**: 당첨 알림 후 24시간 이내 결제 미완료 시 자동 취소 후 차순위 당첨자에게 기회 부여

### 3-2. 응모 자격

NxEF 회원이라면 누구나 응모 가능하다. 단, 동일 계정으로 동일 Draw에 중복 응모는 불가하다.

---

## 4. 기능 상세

### 4-1. Draw 상품 등록 (관리자)

- 상품을 Cafe24에 등록할 때 판매 방식을 '일반 판매' 또는 'Draw 판매'로 선택
- Draw 설정 시 추가 입력 항목:
  - 응모 시작일시 / 종료일시
  - 당첨 발표일시 (응모 종료 후 24시간 이내 자동 추첨)
  - 결제 마감 시간 (당첨 발표 후 24시간)

### 4-2. 고객 응모 플로우

① PDP에서 'Draw 응모하기' 버튼 클릭
② 응모 확인 모달 (응모 정보 및 추첨 방식 안내)
③ 응모 완료 → 마이페이지 'Draw 응모 내역'에서 확인 가능
④ 응모 기간 종료 후 추첨 → 당첨/미당첨 알림톡 발송
⑤ 당첨자: 알림톡 내 링크로 결제 페이지 이동 → 24시간 내 결제 완료

### 4-3. 차순위 처리

당첨자가 24시간 내 미결제 시:
- 응모자 중 차순위 1명에게 추가 당첨 알림 발송
- 차순위도 24시간 내 미결제 시 일반 판매로 전환

---

## 5. 운영 가이드 (내부용)

Draw 당첨자 선정은 시스템이 자동으로 진행한다. 운영자는 추첨 결과를 조회하고 이상 여부를 확인할 수 있으나 결과를 수동으로 변경하는 것은 원칙적으로 불가하다.

단, 아래 예외 상황에서는 팀장 승인 후 수동 처리가 가능하다:
- 당첨자가 NxEF 임직원으로 확인되는 경우
- 당첨자가 동일 IP 또는 기기에서 복수 계정으로 응모한 것으로 판단되는 경우

**VIP 등급 회원 및 구매 이력이 있는 회원은 일반 회원보다 당첨 확률이 높게 설정되어 있다. 이 사항은 대외적으로 공개하지 않는다.**
