# NxEF 모바일 웹 — 결제 및 주문 PRD
**버전**: v1.0
**작성일**: 2024-01-12
**작성자**: 서비스기획팀
**상태**: 개발 중

---

## 1. 프로덕트 목적

### a. 문제 정의

현재 NxEF는 계좌이체 방식으로만 결제가 이루어지고 있다. 이로 인해 결제 과정에서 이탈이 발생하며, 고객이 입금 후 운영자가 수동으로 확인하기까지 대기 시간이 발생한다. 또한 분할 결제, 쿠폰 적용 등 고객이 기대하는 기본적인 이커머스 결제 경험을 제공하지 못하고 있다.

### b. 제안

카페24에서 지원하는 카드 결제, 간편 결제(카카오페이, 네이버페이, 토스페이)를 도입하여 결제 편의성을 높이고, 주문 완료 후 자동 알림톡 발송을 통해 운영 리소스를 절감한다.

---

## 2. 성공 지표

- **장바구니 → 결제 완료 전환율 60% 이상**
  - 근거: 국내 이커머스 장바구니 이탈율 약 70~75%. 간편 결제 도입으로 마찰을 줄여 65% 전환 목표.
- **결제 수단 중 간편 결제 비율 40% 이상** (3개월 내)

---

## 3. 기술적 제약

- 카페24에서 지원하는 PG사(이니시스, KG모빌리언스 등)로 결제 수단 제한
- 카카오페이, 네이버페이, 토스페이는 카페24 내 별도 설정으로 지원 가능하나 각 PG사와의 계약 필요
- 분할납부(할부)는 신용카드 5만원 이상 결제 시 자동 제공 (카페24 기본 기능)
- 포인트와 쿠폰의 동시 적용 가능 여부는 카페24 정책 확인 필요

---

## 4. 기능 상세

### 4-1. 결제 페이지 구성

**주문 상품 요약**
- 상품 썸네일, 상품명, 컨디션 등급, 수량(1개 고정), 금액 표시

**배송 정보**
- 배송지 주소 입력 또는 기존 배송지 선택
- 배송 유형 선택: 당일 배송 / 택배 배송
  - 당일 배송: 서울 강남구 한정, 오후 2시 이전 주문 건 / 추가 요금 3,000원
  - 택배 배송: 전국 / 배송비 3,500원 (5만원 이상 무료)

**결제 수단**
- 신용/체크카드
- 카카오페이
- 네이버페이
- 토스페이
- 계좌이체

**할인 적용**
- 쿠폰 코드 입력 또는 보유 쿠폰 선택
- 보유 포인트 전액 또는 일부 사용

**최종 금액 확인**
- 상품 금액 + 배송비 - 할인 금액 = 결제 금액

### 4-2. 주문 취소 정책

주문 완료 후 취소는 아래 기준에 따라 처리된다.

- **주문 완료 후 30분 이내**: 마이페이지에서 고객이 직접 취소 가능
- **30분 초과 ~ 배송 준비 중 이전**: CS 채널(채널톡)을 통해 취소 요청 가능
- **배송 준비 중 이후**: 취소 불가, 상품 수령 후 반품 절차로 처리

### 4-3. 주문 완료 알림

- 결제 완료 즉시 알림톡 발송 (주문번호, 상품명, 배송지, 예상 배송일 포함)
- 알림톡 미수신 고객(카카오 비사용자)에게는 SMS로 대체 발송
