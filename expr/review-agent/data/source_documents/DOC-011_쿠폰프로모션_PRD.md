# NxEF 쿠폰/프로모션 PRD
**버전**: v1.0
**작성일**: 2024-01-28
**작성자**: 서비스기획팀
**상태**: 개발 대기

---

## 1. 프로덕트 목적

### a. 문제 정의

현재 NxEF는 고객에게 별도의 할인 혜택을 제공할 수 있는 수단이 없다. 신규 고객 유치, 재구매 유도, 체류 재고 소진 등을 위해 쿠폰 및 프로모션 기능이 필요하다. 특히 명품 중고 상품은 가격 민감도가 높아 소폭의 할인도 구매 결정에 영향을 미치는 경향이 있다.

또한 현재 SNS를 통해 비공개 할인 코드를 일부 고객에게 수동으로 전달하고 있으나, 이를 체계적으로 관리할 수 있는 어드민 기능이 없어 관리 리소스가 과도하게 소요되고 있다.

### b. 제안

관리자가 쿠폰을 생성하고 발급 대상을 관리할 수 있는 어드민 기능을 도입하고, 고객은 결제 시 쿠폰 코드를 입력하거나 보유 쿠폰을 선택하여 할인을 받을 수 있게 한다.

---

## 2. 배경 및 현황

카페24 플랫폼에서는 기본적인 쿠폰 기능을 제공하고 있으나, 발급 조건과 적용 범위가 제한적이다. 현재 운영 중인 SNS 비공개 할인 코드 방식은 코드가 외부에 유출될 위험이 있으며, 사용 여부 추적이 불가하여 할인 효과를 측정할 수 없다. 이를 개선하기 위해 카페24의 쿠폰 기능을 최대한 활용하되, 부족한 부분은 자체 어드민에서 보완한다.

---

## 3. 성공 지표

- **쿠폰 적용 주문의 구매 전환율이 미적용 주문 대비 1.3배 이상**
- **발급된 쿠폰의 실제 사용율 30% 이상**
- **신규 가입 쿠폰 발급 후 첫 구매 전환율 15% 이상**

---

## 4. 쿠폰 유형

| 유형 | 설명 | 예시 |
|------|------|------|
| 정액 할인 | 고정 금액 할인 | 10,000원 할인 |
| 정률 할인 | 비율 할인 | 5% 할인 |
| 배송비 할인 | 배송비 전액 또는 일부 할인 | 배송비 무료 |
| 신규 가입 쿠폰 | 가입 즉시 자동 발급 | 5,000원 할인 |
| 친구 추천 쿠폰 | 추천인·피추천인 모두 발급 | 각 3,000원 할인 |

## 5. 기능 상세

### 5-1. 관리자 쿠폰 생성

관리자가 어드민에서 쿠폰을 생성할 때 입력하는 정보:

| 항목 | 내용 |
|-----|------|
| 쿠폰명 | 내부 관리용 이름 |
| 쿠폰 코드 | 직접 입력 또는 자동 생성 (8자리) |
| 할인 유형 | 정액 / 정률 / 배송비 |
| 할인 금액/율 | 숫자 입력 |
| 최소 주문 금액 | 없음 또는 금액 설정 |
| 최대 할인 금액 | 정률 쿠폰에서 상한선 설정 가능 |
| 유효 기간 | 시작일 ~ 종료일 |
| 발급 수량 | 무제한 또는 수량 제한 |
| 사용 가능 카테고리 | 전체 또는 특정 카테고리 지정 |

### 5-2. 고객 쿠폰 사용

- 결제 페이지에서 쿠폰 코드 직접 입력 또는 보유 쿠폰 목록에서 선택
- 1회 결제당 쿠폰 1매 사용 가능
- 쿠폰과 포인트 동시 사용 가능
- 쿠폰과 회원 등급 할인 동시 사용 가능

### 5-3. 신규 가입 쿠폰 자동 발급

- 회원가입 완료 즉시 5,000원 정액 쿠폰 자동 발급
- 유효 기간: 가입일로부터 30일
- 최소 주문 금액: 50,000원 이상
