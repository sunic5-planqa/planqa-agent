# NxEF A/B 테스트 운영 기획서
**버전**: v1.0
**작성일**: 2024-02-20
**작성자**: 서비스기획팀
**상태**: 확정

---

## 1. 개요

NxEF 모바일 웹 오픈 후 6개월간 핵클(Hackle) SDK를 활용하여 A/B 테스트를 운영한다. 테스트 베드로서의 역할을 최대한 수행하여, 추후 자체 플랫폼 개발 시 검증된 데이터 기반의 설계를 적용할 수 있도록 한다.

---

## 2. 핵심 목표 (KPI)

- **구매 전환율 1.5% 달성** (홈 → 상품 상세 → 장바구니 → 결제 완료 기준)
  - 참고: 국내 이커머스 평균 전환율 1.33%, 해외 패션 이커머스 중앙값 1.96%
- **월 2회 이상 A/B 테스트 진행 및 통계적으로 유의미한 승자 도출**

---

## 3. A/B 테스트 계획 (1차 스프린트: 오픈 후 8주)

### Week 1-2: 홈 화면 레이아웃 테스트

**테스트명**: 홈 상단 섹션 — 기획전 배너 vs 카테고리 퀵링크 우선 노출

| 구분 | A안 (Control) | B안 (Variant) |
|-----|-------------|-------------|
| 홈 최상단 | 기획전 배너 (전체 폭) | 카테고리 퀵링크 4개 |
| 2번째 섹션 | 카테고리 퀵링크 | 기획전 배너 |
| 측정 지표 | 홈 → PDP 진입율 | 홈 → PDP 진입율 |

**가설**: 탐색 의도가 명확한 방문자(카테고리 퀵링크 우선)가 더 높은 PDP 진입율을 보일 것이다.

---

### Week 3-4: 홈 상품 카드 썸네일 테스트

**테스트명**: 신규 입고 섹션 상품 카드 — 단독 상품 사진 vs 코디 착샷

| 구분 | A안 (Control) | B안 (Variant) |
|-----|-------------|-------------|
| 썸네일 | 상품 단독 사진 (흰 배경) | 실착 코디 사진 |
| 측정 지표 | 홈 섹션 → PDP 진입율 | 홈 섹션 → PDP 진입율 |

**가설**: 착용 컨텍스트가 있는 코디 사진이 클릭을 더 유도할 것이다.

---

### Week 5-6: 홈 섹션 순서 테스트

**테스트명**: 홈 중간 섹션 — MD 추천 vs 신규 입고 순서

| 구분 | A안 (Control) | B안 (Variant) |
|-----|-------------|-------------|
| 홈 상단 섹션 순서 | 신규 입고 → MD 추천 | MD 추천 → 신규 입고 |
| 측정 지표 | 각 섹션 클릭율 | 각 섹션 클릭율 |

**가설**: MD가 선별한 추천 상품이 상단에 올 때 클릭율과 전환율이 더 높을 것이다.

---

### Week 7-8: 홈 배너 CTA 문구 테스트

**테스트명**: 기획전 배너 CTA 버튼 문구

| 구분 | A안 | B안 | C안 |
|-----|-----|-----|-----|
| 버튼 문구 | "지금 보러가기" | "쇼핑하기" | "상품 보기" |
| 측정 지표 | 배너 CTR | 배너 CTR | 배너 CTR |

## 4. 테스트 운영 기준

### 표본 크기 및 기간

- 최소 표본 크기: 그룹당 500명 (통계적 유의성 기준 95%, 검증력 80%)
- 최소 운영 기간: 7일 (요일 효과 통제)
- 승자 기준: p-value 0.05 이하, 개선율 5% 이상

### 테스트 적용 대상

- 전체 방문자 중 50%에게 적용 (Control 50% / Variant 50%)
- 로그인 회원을 기준으로 실험군 배정 (쿠키 기반 비로그인 회원 포함)

---

## 5. 결과 리뷰 프로세스

- 매주 월요일: 전주 A/B 테스트 결과 리뷰 미팅
- 유의미한 승자 확인 시 → 다음 배포 사이클에 반영
- 유의미한 결과 없을 시 → 기간 연장(최대 2주) 또는 테스트 종료 후 다음 테스트로 전환
