## 1. 요구 배경

### 1-1. 문제 정의
2026년 2분기 해외 로밍 데이터 이용 고객 문의 6,500건을 분석한 결과, 잔여량과 소진 예상 시점을 알고 싶다는 문의가 34%였다. 현재 고객은 T월드 앱에서 잔여량을 직접 확인할 수 있으나, 고객이 원하는 기준에 맞춘 사전 알림을 설정할 수 없어 예상하지 못한 데이터 소진이 발생한다.

### 1-2. 해결 방향
고객이 로밍 데이터 잔여량 알림 기준을 직접 설정하고, 잔여량이 해당 기준에 도달하면 앱 알림과 문자 메시지를 받도록 기능을 개선한다. 알림은 회선별로 관리하며, 고객이 해외 체류 중에도 기준과 수신 방식을 변경할 수 있도록 한다.

## 2. 적용 범위와 사용자

### 2-1. 적용 대상
- 개인 명의 스마트폰 회선
- 데이터 제공량이 정해진 로밍 상품 이용 고객
- T월드 앱 알림 또는 문자 메시지 수신이 가능한 고객

### 2-2. 제외 대상
- 법인 회선
- 데이터 무제한 로밍 상품
- 데이터 로밍이 차단된 회선

### 2-3. 사용자 역할
| 역할 | 권한 |
|---|---|
| 회선 명의자 | 알림 기준 조회·등록·수정·해제 |
| 회선 이용자 | 명의자의 사전 동의가 있는 경우 조회·수정 |
| 고객센터 상담원 | 고객 본인 확인 후 등록·수정 대행 |

## 3. 기능 요구사항

### 3-1. 잔여량 알림 설정
**목적**: 고객이 로밍 데이터 소진 전에 원하는 시점에 알림을 받도록 한다.

**조건**: 고객이 데이터 제공량이 정해진 로밍 상품을 이용 중이고, 회선 본인 인증을 완료해야 한다.

**동작**: 고객은 잔여량 비율 50%, 30%, 10% 중 하나 이상을 선택하고 수신 방식을 앱 알림, 문자 메시지 또는 둘 다로 설정한다.

**결과**: 저장 완료 시 선택한 기준과 수신 방식을 회선 설정에 반영하고 설정 완료 시각을 표시한다.

**예외**: 데이터 무제한 상품이거나 로밍 데이터가 차단된 회선에서는 설정을 저장하지 않고 적용 불가 사유를 안내한다.

### 3-2. 임계값 도달 알림
**목적**: 고객이 설정한 잔여량 기준에 도달했음을 지연 없이 안내한다.

**조건**: 회선의 로밍 데이터 잔여량이 설정값 이하로 처음 내려가고, 같은 기준의 알림을 아직 발송하지 않은 상태여야 한다.

**동작**: 시스템은 잔여량, 전체 제공량, 사용 가능 기한, 추가 상품 구매 경로를 포함한 알림을 생성한다.

**결과**: 앱 알림은 조건 충족 후 1분 이내, 문자 메시지는 3분 이내에 발송하고 발송 결과를 이용 기록에 저장한다.

**예외**: 앱 알림 발송에 실패하면 문자 메시지 수신 동의 여부를 확인한 뒤 문자 메시지로 대체하고, 두 방식 모두 실패하면 고객센터 확인 목록에 등록한다.

### 3-3. 설정 변경 제한
기능 요구사항 07: 동일 회선의 알림 임계값 변경은 하루 최대 2회로 제한한다.

변경 횟수는 한국 표준시 00:00부터 23:59까지 집계한다. 고객이 제한 횟수를 초과하면 다음 변경 가능 시각을 표시하며, 고객센터 상담원도 같은 제한을 적용받는다.

### 3-4. 알림 설정 해제
**목적**: 고객이 더 이상 잔여량 알림을 받지 않도록 설정을 종료한다.

**조건**: 회선에 하나 이상의 알림 기준이 등록되어 있어야 한다.

**동작**: 고객이 설정 해제를 선택하고 해제 내용을 확인한다.

**결과**: 모든 알림 기준과 수신 방식을 비활성화하고 해제 완료 시각을 표시한다.

**예외**: 해제 처리 중 네트워크 연결이 끊기면 요청을 기기에 임시 저장하고 연결 복구 후 다시 처리한다.

## 4. 데이터 및 처리 요구사항
- 잔여량은 로밍 상품의 전체 제공량에서 확정 사용량을 뺀 값으로 계산한다.
- 사용량은 5분 간격으로 갱신하며, 마지막 갱신 시각을 고객 화면에 표시한다.
- 설정 이력, 발송 이력, 실패 사유는 회선별로 12개월 동안 보관한다.
- 알림 기준을 변경하거나 해제하면 변경 전 값과 변경 후 값을 함께 저장한다.
- 동일 기준을 여러 번 통과하더라도 로밍 상품 1건당 해당 기준 알림은 1회만 발송한다.

## 5. 화면 요구사항

### 5-1. 알림 설정 화면
- 화면 상단에는 현재 로밍 상품명, 전체 제공량, 잔여량, 마지막 갱신 시각을 표시한다.
- 설정 화면 상단에는 '알림 설정' 버튼을 배치한다.
- 저장 완료 화면에서도 동일한 버튼을 '잔여량 알림' 버튼으로 표시한다.
- 잔여량 기준은 50%, 30%, 10%를 각각 선택할 수 있는 항목으로 제공한다.
- 수신 방식은 앱 알림, 문자 메시지, 둘 다 중 하나를 선택하도록 한다.
- 저장 전에는 선택한 기준과 수신 방식을 요약하여 확인할 수 있어야 한다.

### 5-2. 이용 기록 화면
- 최근 30일의 알림 발송 시각, 잔여량, 수신 방식, 성공·실패 상태를 최신순으로 표시한다.
- 실패 상태를 선택하면 실패 사유와 대체 발송 여부를 표시한다.
- 데이터가 없으면 알림 발송 기록이 없다는 안내를 표시한다.

## 6. 오류 및 예외 처리
| 상황 | 처리 | 고객 안내 |
|---|---|---|
| 잔여량 데이터 갱신 지연 | 마지막 확정값을 유지하고 갱신 시각 표시 | 현재 잔여량이 지연될 수 있음 |
| 회선 본인 인증 실패 | 설정 저장 차단 | 본인 인증 후 다시 시도 |
| 앱 알림 발송 실패 | 문자 메시지 대체 발송 | 문자 메시지로 안내함 |
| 두 발송 방식 모두 실패 | 고객센터 확인 목록 등록 | 발송 실패와 확인 예정 시각 표시 |
| 로밍 상품 종료 | 미발송 알림 기준 비활성화 | 상품 종료로 알림 설정을 종료함 |

## 7. 검수 기준
- 고객이 선택한 잔여량 기준과 수신 방식이 저장 후 동일하게 표시되어야 한다.
- 잔여량이 기준값 이하로 처음 내려간 시점부터 앱 알림은 1분, 문자 메시지는 3분 이내에 발송되어야 한다.
- 같은 로밍 상품과 같은 기준에서는 알림이 두 번 이상 발송되지 않아야 한다.
- 변경 제한 횟수와 다음 변경 가능 시각이 고객 화면과 상담원 화면에서 동일해야 한다.
- 해제 완료 후에는 새로운 잔여량 알림이 생성되지 않아야 한다.
