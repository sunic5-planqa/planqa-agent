# DOC-040: 사내 채용 지원 시스템 (ATS) PRD
**버전**: v1.0
**작성일**: 2024-03-28
**작성자**: 플랫폼기획팀
**상태**: 확정

## 1. 프로덕트 목적

채용 공고 등록부터 지원자 관리, 면접 일정 조율까지 채용 전 과정을 하나의 시스템에서 관리한다.

## 2. 요구사항

지원자 경험을 개선하기 위해, **지원자는 서류 접수 완료 후 언제든 자유롭게 지원서 내용을 수정**할 수 있도록 한다.

## 3. 정책

### 3-1. 지원서 수정 정책

채용 공정성 확보를 위해 **지원서는 접수 완료 시점에 즉시 잠금 처리되며, 이후 수정이 일체 불가능**하다.

## 4. 상위 요구사항 (참고: 개인정보보호 정책서)

전사 개인정보보호 정책서에 따르면, **채용 전형에서 탈락한 지원자의 개인정보는 전형 종료 후 6개월 이내 파기**되어야 한다.

## 5. 기능 상세

### 5-1. 지원자 정보 보관

시스템은 탈락한 지원자의 이력서 및 개인정보를 **차기 채용 시 재활용할 수 있도록 별도 삭제 절차 없이 3년간 보관**한다.
