**작성자**: 서비스기획팀
**상태**: 확정

## 1. 프로덕트 목적

### a. 문제 정의

현재 고객과의 커뮤니케이션이 인스타그램 DM에 의존하고 있어 다음 문제가 발생한다:
- 주문 상태 변경 시 고객에게 즉각적인 안내가 불가
- 운영자가 주문 건마다 수동으로 메시지를 보내야 하는 리소스 낭비
- 입고 알림 신청 고객에게 알림을 발송할 체계 없음

내부 운영팀 역시 입금 확인, 입고 완료 등의 이벤트를 실시간으로 파악할 수 없어 슬랙을 통한 수동 공유에 의존하고 있다.

### b. 제안

고객 대상 알림은 카카오 알림톡(비사용자는 SMS 대체), 내부 운영 알림은 슬랙으로 통합 설계한다.

---

## 2. 성공 지표

- **주문 관련 알림톡 발송 성공율 99% 이상**
- **입고 알림 발송 후 48시간 내 구매 전환율 10% 이상**
  - 근거: 입고 알림은 구매 의향이 높은 고객에게 발송되므로 일반 방문자 대비 높은 전환율 기대
- **내부 슬랙 알림을 통해 입금 확인 처리 시간 1시간 이내 달성**

## 4. 알림톡 메시지 설계

### 주문 완료 알림

```
[NxEF] 주문이 완료되었습니다.

주문번호: #{order_id}
상품명: #{product_name}
결제금액: #{payment_amount}원
배송지: #{address}

상품은 영업일 기준 1~3일 이내 발송됩니다.
문의: cs@nxef.co.kr
```

### 배송 출발 알림

```
[NxEF] 주문하신 상품이 발송되었습니다.

상품명: #{product_name}
택배사: CJ대한통운
운송장 번호: #{tracking_number}

배송 조회: [CJ대한통운 조회하기]
```

### 입고 알림

```
[NxEF] 알림 신청하신 상품이 입고되었습니다.

상품명: #{product_name}
컨디션: #{condition_grade}
판매가: #{price}원

지금 바로 확인하기: #{pdp_url}

※ 중고 단일 재고 상품으로, 조기 품절될 수 있습니다.
```

## 5. 입고 알림 신청 기능

### 5-1. 고객 신청 Flow

① PDP에서 '입고 알림 신청' 버튼 클릭 (품절 상품 한정)
② 신청 모달: 원하는 사이즈 선택 (스니커즈 한정), 최대 희망 가격 입력 (선택)
③ 신청 완료 시 "입고 시 알림을 보내드립니다" 확인 메시지

### 5-2. 알림 발송 기준

- 해당 모델과 동일한 사이즈의 상품이 입고될 때 알림 발송
- 고객이 최대 희망 가격을 입력한 경우, 입고 가격이 그 이하일 때만 발송
- 입고 알림 신청 후 6개월 내 해당 상품 미입고 시 신청 자동 만료 후 안내 메시지 발송
