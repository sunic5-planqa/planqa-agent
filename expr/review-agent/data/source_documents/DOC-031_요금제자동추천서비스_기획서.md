# SKT 요금제 자동 추천 서비스 기획서
**버전**: v1.0
**작성일**: 2024-04-05
**작성자**: 서비스기획팀
**상태**: 검토 중

---

## 1. 프로덕트 목적

SKT 5G 요금제 이용 고객에게 현재 이용 패턴에 맞는 최적 요금제를 T world 앱을 통해 자동으로 추천하는 기능을 도입한다. 고객은 매월 요금제 변경 메뉴 진입 시 추천 배너를 통해 더 적합한 요금제를 확인할 수 있다.

---

## 2. 기능 상세

### 2-1. 추천 로직

T world 앱 '요금제 변경' 메뉴 진입 시, 고객에게 현재보다 더 적합한 SKT 5G 요금제를 자동으로 추천한다. 추천 결과는 화면 상단에 "고객님께 이런 요금제를 추천드려요" 배너로 노출된다.

### 2-2. 추천 알고리즘 개요

추천은 고객의 최근 3개월 데이터 사용량, 통화량, 로밍 이용 이력을 종합하여 산정된다.

### 2-3. VIP 고객 우선 추천

**VIP 고객에게는 추천 결과가 우선적으로 제공되며, 배너 노출 순위도 상향된다.**

### 2-4. 추천 갱신 주기

- 매월 1회 배치로 전체 고객 대상 추천 결과를 갱신
- 요금제 변경 직후에는 즉시 재계산하여 반영

### 2-5. 고객 반응 처리

- 추천 요금제를 클릭하면 요금제 변경 페이지로 바로 이동
- "다시 보지 않기" 선택 시 해당 배너는 30일간 미노출

---

## 3. 알고리즘 고도화 로드맵

- 1차: 데이터 사용량 기준 단순 매칭
- 2차: 통화량, 로밍 이용 이력 등 추가 반영
- 3차: 유사 고객군 기반 협업 필터링 도입 검토
