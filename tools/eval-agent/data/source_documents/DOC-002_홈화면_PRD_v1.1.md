**버전**: v1.1
**작성일**: 2024-01-22
**작성자**: 서비스기획팀
**상태**: 확정
**변경 이력**: v1.0 → v1.1 당일 배송 권역 확대 반영

---

## 1. 프로덕트 목적

### a. 문제 정의

NxEF 모바일 웹 오픈 이후 초기 데이터 분석 결과, 고객의 주요 이탈 지점이 홈 화면에서 상품 상세 페이지로의 진입 단계임이 확인되었다. v1.0에서 설계한 홈 화면 구조는 대체로 유효하나, 아래 사항을 추가 반영한다.

- 당일 배송 서비스 권역이 초기 강남구 한정에서 **서울 전 지역으로 확대**됨에 따라 홈 화면 배너 및 안내 문구 업데이트 필요
- 신규 입고 상품 섹션의 체류 시간이 타 섹션 대비 낮아, 섹션 제목 및 상품 카드 디자인 개선 필요

### b. 제안

당일 배송 권역 확대를 홈 화면 메인 배너를 통해 고객에게 노출하고, 신규 입고 섹션의 상품 카드에 컨디션 등급 태그를 추가하여 탐색 효율을 높인다.

## 5. 기능 상세 변경 사항

### 5-1. 당일 배송 안내 배너 추가

- 홈 화면 카테고리 퀵링크 하단에 당일 배송 안내 띠 배너 추가
- 문구: "서울 전 지역 당일 배송 가능 | 오후 2시 이전 주문 시"
- 배경색: NxEF 브랜드 컬러(#1A1A1A) / 텍스트: 흰색

### 5-2. 신규 입고 상품 카드 업데이트

- 상품 썸네일 하단에 컨디션 등급 태그(S/A/B/C) 추가
- 태그 색상: S - 골드, A - 그린, B - 블루, C - 그레이

### 5-3. MD 추천 섹션 확대

- 노출 상품 수: 최대 6개 → 최대 8개
- 가로 스크롤 방식으로 변경 (기존 2열 그리드 → 가로 스크롤)

## 6. FAQ 업데이트 (당일 배송 관련)

이번 권역 확대와 함께 웹 내 FAQ 페이지의 배송 관련 항목을 다음과 같이 업데이트한다.

**Q. 당일 배송은 어떤 지역에서 가능한가요?**
A. 당일 배송은 **서울 강남구** 지역 고객을 대상으로 운영 중입니다. 오후 2시 이전 주문 완료 건에 한해 당일 저녁 7시 이전 배송을 보장합니다.

**Q. 당일 배송 상품과 택배 배송 상품이 따로 있나요?**
A. 별도 구분은 없으며, 결제 시 배송 유형을 직접 선택할 수 있습니다. 당일 배송 가능 여부는 고객의 배송지 주소를 기준으로 자동 판별됩니다.
