# DOC-036: 사내 설문조사 시스템 PRD
**버전**: v1.0
**작성일**: 2024-03-24
**작성자**: 플랫폼기획팀
**상태**: 개발 중

## 1. 프로덕트 목적

부서별 만족도 조사, 이벤트 참여 신청 등 다양한 목적의 설문을 손쉽게 만들고 응답 결과를 분석할 수 있는 사내 설문 도구를 구축하여, **설문 응답률을 높여 조직 의사결정의 데이터 기반 근거를 확보한다.**

## 2. 성공 지표

- **평균 설문 응답률 60% 이상**
- **설문 생성부터 결과 분석까지 소요 시간 50% 단축**

## 3. 기능 상세

### 3-1. 응답 현황 조회 (설문 생성자용)

설문 생성자는 현재까지 응답한 인원 수와 응답률을 실시간으로 확인할 수 있다.

### 3-2. 참여 현황 대시보드 (관리자용)

관리자는 전사 설문 목록별로 몇 명이 응답을 완료했는지, 전체 대상자 대비 참여 비율이 어느 정도인지를 대시보드에서 확인할 수 있다.

## 4. 마일스톤
