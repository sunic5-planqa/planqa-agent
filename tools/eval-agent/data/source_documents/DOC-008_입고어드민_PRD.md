**버전**: v1.0
**작성일**: 2024-02-12
**작성자**: 서비스기획팀
**상태**: 확정

---

## 1. 프로덕트 목적

### a. 문제 정의

번개장터에서 상품을 매입한 이후 실제로 상품이 입고되기까지의 단계(입금 확인 → 입고 등록 → 배송 추적)를 모두 수기로 처리하고 있다. 구체적인 문제는 다음과 같다.

1. 매입 완료된 상품의 정보를 스프레드시트에 한 줄씩 수기 입력하며 누락·오타 발생 빈번
2. Cafe24에 상품을 등록할 때 스프레드시트에서 값을 복사·붙여넣기 하는 방식이어서 오류 가능성이 높음
3. 프로세스가 특정 담당자에게 집중되어 있어 대체 인력 투입 시 업무 연속성 확보 어려움
4. 매입 상품은 회사의 자산이며, 자산 목록에 대한 체계적인 DB가 없음

### b. 제안

입고 어드민을 구축하여 **입금 확인 → 상품 정보 등록 → Cafe24 자동 입고** 전 과정을 자동화한다. 이를 통해 수기 입력 오류를 제거하고, 누구든 동일한 방식으로 운영할 수 있는 표준화된 프로세스를 만든다.

---

## 2. 성공 지표

- **입고 처리 시간 50% 단축**: 매입 완료 ~ Cafe24 등록까지 소요 시간을 기존 대비 50% 감소
- **수기 등록 오류 제로**: 자동화 이후 상품코드, 상품명 기입 오류 0건
- **Cafe24 상품 등록 완전 자동화**: 담당자가 Cafe24 어드민에 직접 접근하지 않아도 되는 상태

---

## 3. 기술적 제약

- Cafe24 Open API를 통한 상품 등록 가능. 단, API Key 발급 및 연동 개발 필요
- 번개장터 API 미제공으로 번개장터 채팅 데이터 자동 수집 불가

## 4. 기능 상세

### 4-1. 칸반보드 스테이지 구성

| 스테이지 | 설명 |
|---------|------|
| 입금 전 | 공급자와 거래 협의 완료, 입금 전 상태 |
| 입금 완료 | 입금 확인 완료. 이 단계에서 Cafe24 자동 등록 트리거 |
| 배송 중 | 공급자 발송 완료, 배송 추적 중 |
| 입고 완료 | 상품 수령 및 물리적 검수 완료 |

### 4-2. 카드 생성 및 상품 정보 등록

카드는 '입금 전' 스테이지에서 생성된다.

**상품 정보 입력 프로세스**

① 담당자가 한글 상품명 드롭다운에서 선택
- 선택 시 영문 상품명 자동 입력
- 예: "나이키 덩크 로우 블랙" 선택 → "Nike Dunk Low Black" 자동 입력

② 시스템이 자체상품코드를 자동 부여
- 기존 최고 코드 + 1 방식으로 순번 부여
- 코드 부여 시 영문 상품명 뒤에 자동 추가
- 예: Nike Dunk Low Black → Nike Dunk Low Black _20398

③ 담당자가 추가 정보 직접 입력
- 공급원가 (필수)
- 사이즈 (스니커즈 한정, 선택)
- 구성품 여부 (체크박스)
- 공급자 입금 계좌 (필수)
- 번개장터 상품 링크 (선택)

### 4-3. 입금 확인 및 알림

- 카드를 '입금 전'에 저장하면 슬랙 #입금대기 채널에 자동 알림 발송
  - 알림 내용: 상품명, 공급원가, 입금 계좌
- 입금 담당자가 입금 확인 후 슬랙 이모티콘으로 확인 표시
- 입금 확인 완료 시 담당자가 카드를 '입금 완료' 스테이지로 이동

### 4-4. Cafe24 자동 입고

카드가 '입금 완료' 스테이지로 이동되는 순간:
- Cafe24 Open API 호출하여 상품 자동 등록
- 등록 정보: 영문 상품명(+코드), 공급원가, 사이즈(옵션값), 카테고리

### 4-5. 배송 추적

- '배송 중' 스테이지에서 담당자가 운송장 번호 입력
- 새로고침 시 CJ대한통운 API로 배송 상태 자동 조회
- 결과 표시: 배송 준비 중 / 배송 중 / 배송 완료

## 5. 사용자 시나리오

**정상 시나리오 예시**

1. 담당자가 번개장터에서 [260] Jordan 1 Retro High OG Royal Toe 판매자와 채팅 시작
2. 협의 완료 후 어드민 '입금 전' 스테이지에 카드 생성
   - 한글 상품명: "조던 1 레트로 하이 OG 로열 토" 선택
   - 자동 입력: Jordan 1 Retro High OG Royal Toe _20397
   - 공급원가: 210,000원
   - 입금 계좌: 카카오뱅크 0000-0000-0000 고수진
3. 슬랙 #입금대기 알림 자동 발송
4. 입금 담당자 확인 후 슬랙 이모티콘 처리
5. 카드 '입금 완료'로 이동 → Cafe24 자동 등록
6. 공급자 발송 확인 후 '배송 중'으로 이동, 운송장 번호 입력
7. 배송 완료 확인 후 '입고 완료'로 이동
