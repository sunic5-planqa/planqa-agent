**버전**: v1.0
**작성일**: 2024-02-05
**작성자**: 서비스기획팀
**상태**: 개발 중

---

## 1. 프로덕트 목적

### a. 문제 정의

NxEF의 판매 상품 100%는 번개장터, 중고나라 등 C2C 플랫폼에서의 **매입**을 통해 소싱된다. 현재 매입 프로세스는 전적으로 담당자의 수작업에 의존하며 아래와 같은 문제가 있다.

- 예상 매출 달성을 위해 매주 프라이탁 40개, 스니커즈 60개 이상 매입 필요
- 매입 시마다 100명 이상의 판매자와 개별 채팅 진행 필요
- 입금 처리, 운송장 트래킹, 입고 등록을 스프레드시트로 수기 관리
- 특정 담당자에게 프로세스가 집중되어 대체 인력 투입 시 인수인계 어려움

### b. 제안

번개장터 기반의 **구매** 현황을 한 곳에서 관리할 수 있는 칸반보드 형태의 어드민 대시보드를 구축한다. 매입 ~ 입고까지의 전 과정을 시각화하고 반복 작업을 자동화하여 운영 효율을 높인다.

## 2. 경쟁/참고 사례

| 서비스 | 특징 | 참고 포인트 |
|--------|------|-----------|
| 트렐로(Trello) | 칸반보드 방식 업무 관리 | 스테이지 이동, 카드 구성 방식 |
| 노션(Notion) | DB 기반 업무 관리 | 필터·정렬 기능 |
| 번개장터 어드민 | 판매자 대시보드 | 거래 현황 표시 방식 |

---

## 3. 성공 지표

- **매입 처리 시간 30% 단축**: 번개장터 채팅 시작 ~ 입고 등록 완료까지 소요 시간 현행 대비 30% 감소
- **수기 입력 오류율 0건 달성**: 자동화를 통해 상품코드, 상품명 수기 기입 오류 제거
- **담당자 대체 투입 시간 1일 이내**: 신규 담당자가 1일 이내 독립적으로 운영 가능

---

## 4. 기술적 제약

- 번개장터 공식 API가 없어 데이터 자동 수집 불가
  - 대안: 담당자가 번개장터 상품 URL을 입력하면 상품명, 가격을 크롤링하는 방식 검토
- 번개장터 채팅 기능을 어드민 내에서 구현 불가 → 기존 번개장터 앱 병행 사용
- 모바일 환경 미지원 (PC 전용)

## 5. 기능 상세

### 5-1. 칸반보드 구성

하나의 대시보드는 아래 스테이지로 구성된다.

| 스테이지 | 의미 | 트리거 |
|---------|------|-------|
| 구매 협의 중 | 판매자와 가격 협의 진행 중 | 카드 수동 등록 시 |
| 입금 대기 | 협의 완료, 입금 전 | 담당자 수동 이동 |
| 입금 완료 | 입금 확인 완료 | 담당자 수동 이동 |
| 배송 중 | 운송장 번호 입력 후 발송 확인 | 담당자 수동 이동 |
| 입고 완료 | 상품 수령 및 검수 완료 | 담당자 수동 이동 |

### 5-2. 카드 구성 요소

카드에 입력하는 정보:

| 필드 | 입력 방식 | 필수 여부 |
|-----|---------|---------|
| 한글 상품명 | 드롭다운 선택 | 필수 |
| 영문 상품명 | 한글 상품명 선택 시 자동 입력 | 자동 |
| 자체상품코드 | 자동 부여 | 자동 |
| 공급원가 | 직접 입력 | 필수 |
| 사이즈 | 직접 입력 (스니커즈 한정) | 선택 |
| 구성품 | 체크박스 선택 | 선택 |
| 번개장터 판매자 ID | 직접 입력 | 선택 |
| 구매 채널 | 드롭다운 (번개장터/중고나라/기타) | 필수 |
| 운송장 번호 | 직접 입력 | 배송 중 스테이지에서 필수 |

### 5-3. 슬랙 알림

- 카드가 '입금 대기' 스테이지에 등록되면 #입금대기 채널에 알림 발송
  - 알림 내용: 상품명 / 공급원가 / 입금 계좌
- 카드가 '입고 완료'로 이동하면 #입고완료 채널에 알림 발송

### 5-4. 배송 상태 자동 조회

- '배송 중' 스테이지에서 새로고침 시 운송장 번호로 CJ대한통운 배송 상태 자동 조회
- 배송 완료 확인 시 '입고 완료'로 자동 이동 (담당자 확인 후 최종 확정)

### 5-5. Cafe24 자동 입고

- 카드가 '입고 완료' 스테이지로 이동하면 Cafe24에 상품이 자동 등록됨
- 자동 등록 정보: 한글 상품명, 영문 상품명, 자체상품코드, 공급원가, 사이즈(옵션)
