# NxEF 모바일 웹 — 검색 및 필터 PRD
**버전**: v1.0
**작성일**: 2024-01-15
**작성자**: 서비스기획팀
**상태**: 개발 중

---

## 1. 프로덕트 목적

### a. 문제 정의

현재 NxEF 웹에서 상품을 찾으려면 카테고리 탐색을 통해 전체 상품을 스크롤해야 한다. 특정 모델, 사이즈, 컨디션을 원하는 고객이 원하는 상품을 빠르게 찾을 수 없어 이탈이 발생한다. 특히 스니커즈 카테고리에서 사이즈가 맞지 않는 상품을 걸러내는 기능이 없어 불편함이 크다.

### b. 제안

키워드 검색과 다차원 필터(카테고리, 컨디션, 사이즈, 가격대) 기능을 도입하여 원하는 상품을 빠르게 탐색할 수 있게 한다.

---

## 2. 성공 지표

- **검색 사용 고객의 PDP 진입율이 미사용 고객 대비 1.5배 이상**
- **검색 후 결과 없음 발생 비율 10% 이하**

---

## 3. 기술적 제약

- 카페24 기본 검색 기능 활용 가능하나 검색 알고리즘 커스터마이징은 어려움
- 사이즈 필터는 카페24 상품 옵션과 연동 가능 여부 확인 필요

---

## 4. 기능 상세

### 4-1. 키워드 검색

- 홈 화면 상단 검색 아이콘 클릭 시 검색 화면으로 진입
- 검색 대상: 상품명(한글/영문), 브랜드명, 모델명
- 검색 결과는 **관련도 순**으로 정렬되며, 사용자가 정렬 기준을 변경할 수 있다
  - 정렬 옵션: 관련도 순 / 최신 입고순 / 낮은 가격순 / 높은 가격순
- 검색 결과 없을 경우: "찾으시는 상품이 없습니다. 입고 알림을 신청해보세요" + 알림 신청 버튼

### 4-2. 카테고리별 상품 목록 (SRP)

카테고리 탭 클릭 시 해당 카테고리의 전체 상품 목록 표시.

**필터 옵션**

| 필터 | 선택 방식 | 옵션 |
|-----|---------|------|
| 컨디션 | 다중 선택 | S / A / B / C |
| 사이즈 | 다중 선택 | 240 ~ 290 (스니커즈 한정) |
| 가격대 | 슬라이더 | 0원 ~ 최대 가격 |
| 구성품 | 단일 선택 | 전체 / 구성품 완전 / 구성품 없음 |

**정렬 옵션**
- 최신 입고순 (기본값)
- 낮은 가격순
- 높은 가격순

### 4-3. 상품 카드 구성 (SRP)

각 상품 카드에 표시되는 정보:
- 상품 썸네일
- 브랜드명
- 상품명
- 컨디션 등급 태그
- 사이즈 (스니커즈 한정)
- 판매가

### 4-4. 최근 검색어

- 로그인 회원의 최근 검색어 최대 10개 저장
- 검색 화면 진입 시 최근 검색어 목록 표시
- 개별 삭제 또는 전체 삭제 가능
