# DOC-039: 출장 경비 정산 시스템 PRD
**버전**: v1.0
**작성일**: 2024-03-27
**작성자**: 플랫폼기획팀
**상태**: 검토 중

## 1. 프로덕트 목적

출장 경비 영수증 제출과 정산 승인 절차를 전산화하여 정산 소요 기간을 단축한다.

## 2. 요구사항

잦은 출장으로 인한 직원의 정산 부담을 줄이기 위해, **출장 경비는 영수증 제출 없이도 건당 5만원 이하는 정액으로 자동 승인**되도록 한다.

## 3. 정책

### 3-1. 영수증 제출 정책

정산 신뢰성 확보를 위해 **모든 출장 경비 항목은 예외 없이 영수증 첨부가 필수**이며, 영수증 미첨부 건은 정산이 반려된다.

## 4. 기능 상세

### 4-1. 경비 항목 입력

직원은 출장별로 경비 항목(교통비/숙박비/식비 등)과 금액을 입력하고 영수증 사진을 첨부한다.

### 4-2. 정산 예시 안내

**정산 예시**: 김OO 사원이 지방 출장 중 택시비 15,000원을 지출한 경우, 영수증 사진을 첨부하여 정산 신청하면 팀장 승인 후 익월 급여와 함께 지급된다.

## 5. 소액 경비 정산 가이드

소액 경비 정산도 동일한 절차를 거친다. 정산 예시: 김OO 사원이 지방 출장 중 택시비 15,000원을 지출한 경우, 영수증 사진을 첨부하여 정산 신청하면 팀장 승인 후 익월 급여와 함께 지급된다.

## 6. 마일스톤
