# 01. 운영 지표 개요

## 1-1. 목적

본 문서는 T map EV 충전 서비스의 검색 기능 운영 지표를 정의하고, 검색 품질과 사용자 이용 경험을 지속적으로 관리하기 위한 측정 기준을 수립하는 것을 목적으로 한다.

운영 지표는 검색 기능의 성능, 정확도, 사용성 및 서비스 안정성을 종합적으로 관리하기 위한 기준으로 활용하며, 운영 현황 분석 및 서비스 개선의 기초 데이터로 사용한다.

---

## 1-2. 적용 범위

본 운영 지표는 EV 충전 서비스의 검색 기능과 관련된 전 영역에 적용한다.

| 구분 | 적용 여부 |
| --- | --- |
| 충전소 검색 | O |
| 주소 검색 | O |
| 충전기 유형 검색 | O |
| 운영 상태 검색 | O |
| 즐겨찾기 검색 | O |
| 통합 검색 | O |

---

## 1-3. 운영 목표

검색 기능 운영의 주요 목표는 다음과 같다.

- 사용자가 원하는 충전소를 빠르게 찾을 수 있도록 지원한다.
- 검색 결과의 정확성을 지속적으로 유지한다.
- 검색 응답 시간을 안정적으로 관리한다.
- 검색 이용 데이터를 기반으로 품질을 개선한다.
- 검색 실패율을 최소화한다.

---

## 1-4. 주요 운영 지표

| 구분 | 지표 |
| --- | --- |
| 검색 성능 | 평균 응답시간 |
| 검색 품질 | 검색 성공률 |
| 사용자 행동 | 검색 이용률 |
| 검색 결과 | 클릭률(CTR) |
| 서비스 안정성 | 오류율 |

각 지표는 운영 대시보드를 통해 실시간으로 확인할 수 있도록 구성한다.

---

## 1-5. 용어 정의

| 용어 | 정의 |
| --- | --- |
| 검색 요청 | 사용자가 검색을 실행한 건 |
| 검색 성공 | 검색 결과가 정상 반환된 건 |
| 검색 실패 | 결과 미반환 또는 오류 발생 |

---

## 1-6. 데이터 수집 기준

검색 관련 이벤트는 다음 항목을 기준으로 수집한다.

- 검색 실행
- 검색 결과 조회
- 검색 결과 클릭
- 검색 실패
- 검색 종료

모든 이벤트는 운영 로그와 분석 로그를 분리하여 저장한다.

# 02. 운영 지표 정의

## 2-1. 검색 이용률

검색 이용률은 전체 서비스 이용자 중 검색 기능을 이용한 사용자의 비율을 의미한다.

**산출 기준**

> 검색 이용률 = 검색 이용 사용자 수 / 전체 활성 사용자 수 × 100
> 

일별·주별·월별 추이를 함께 관리한다.

---

## 2-2. 검색 성공률

검색 성공률은 정상적으로 검색 결과를 제공한 비율을 의미한다.

| 항목 | 설명 |
| --- | --- |
| 분자 | 검색 성공 건수 |
| 분모 | 전체 검색 요청 건수 |

검색 API 오류는 성공 건수에서 제외한다.

---

## 2-3. 평균 검색 응답시간

검색 요청부터 결과 반환까지 소요된 평균 시간을 의미한다.

측정 대상은 다음과 같다.

- 검색 API 처리시간
- 서버 응답시간
- 결과 반환시간

네트워크 환경에 따른 단말 지연은 별도 지표로 관리한다.

---

## 2-4. 검색 결과 클릭률(CTR)

검색 결과 클릭률은 검색 결과 중 실제 선택된 비율을 의미한다.

**산출 기준**

> CTR = 검색 결과 클릭 수 / 검색 결과 노출 수 × 100
> 

CTR은 검색 품질을 평가하는 주요 지표로 활용한다.

---

## 2-5. 검색 실패율

검색 실패율은 검색 결과를 제공하지 못한 비율을 의미한다.

다음 경우를 실패로 정의한다.

- 검색 결과 없음
- API 오류
- 서버 오류
- 타임아웃
- 시스템 장애

실패 사유는 유형별로 분류하여 운영한다.

---

## 2-6. 검색 로그 관리

검색 이벤트는 다음 정보를 저장한다.

| 저장 항목 | 설명 |
| --- | --- |
| 사용자 ID | 익명 식별자 |
| 검색어 | 입력 키워드 |
| 검색 시간 | 요청 시각 |
| 검색 결과 수 | 반환 건수 |
| 클릭 여부 | 결과 선택 여부 |
| 단말 OS | Android / iOS |

로그는 운영 분석과 검색 품질 개선을 위한 데이터로 활용한다.

# 03. 개선 방안

## 3-1. 검색 엔진 개선

검색 성능 향상을 위해 검색 엔진을 **Elasticsearch**로 교체한다.

적용 이후 신규 검색 엔진을 기준으로 운영한다.

---

## 3-2. 검색 결과 개선

검색 결과는 사용자 이용 패턴을 반영하여 우선순위를 조정한다.

검색 결과의 일관성을 유지하기 위해 동일 조건에서는 동일한 정렬 기준을 적용한다.

---

## 3-3. 검색 화면 개선

검색 화면에서는 최근 검색어와 즐겨찾기 충전소를 함께 제공한다.

검색창은 서비스 전 영역에서 동일한 UI 정책을 적용한다.

---

## 3-4. 검색 운영 모니터링

검색 품질은 운영 대시보드를 통해 실시간으로 확인한다.

다음 항목을 상시 모니터링한다.

- 검색 성공률
- 검색 실패율
- 평균 응답시간
- CTR
- API 오류율

---

## 3-5. 운영 리포트

검색 운영 결과는 주간 및 월간 단위로 집계한다.

보고 항목은 다음을 포함한다.

- 주요 KPI
- 검색 이용 추이
- 검색 오류 현황
- 검색 품질 변화
- 운영 개선 과제

---

# 04. 검색 운영 정책

## 4-1. 검색 대상 데이터 관리

검색 대상은 서비스 운영 상태가 정상인 EV 충전소 정보만 포함한다.

검색 대상 데이터는 다음 조건을 만족해야 한다.

| 구분 | 검색 대상 포함 여부 |
| --- | --- |
| 운영 중 충전소 | O |
| 점검 중 충전소 | O |
| 운영 종료 충전소 | X |
| 삭제 예정 충전소 | X |
| 관리자 비노출 충전소 | X |

운영 상태 변경 시 검색 인덱스는 운영 정책에 따라 갱신한다.

---

## 4-2. 검색어 관리 정책

검색어는 사용자가 입력한 원문을 기준으로 저장한다.

운영 정책에 따라 다음 정보를 함께 관리한다.

- 검색 빈도
- 최근 검색 시각
- 검색 성공 여부
- 검색 결과 수
- 클릭 여부

검색어 로그는 검색 품질 개선 및 운영 분석 목적으로 활용한다.

---

## 4-3. 자동완성 운영 정책

자동완성 기능은 검색 입력 단계에서 사용자 편의성을 높이기 위해 제공한다.

자동완성 후보는 다음 기준으로 생성한다.

- 최근 검색어
- 인기 검색어
- 충전소 명칭
- 주소
- 지역명

동일 검색어가 중복될 경우 하나의 후보만 노출한다.

---

## 4-4. 검색 결과 정렬 정책

검색 결과는 기본적으로 거리순을 우선 적용한다.

동일 거리의 충전소는 다음 순서를 따른다.

1. 운영 가능 여부
2. 급속 충전 가능 여부
3. 사용자 평점
4. 최근 이용량

사용자가 정렬 기준을 변경한 경우 선택한 정렬 방식을 우선 적용한다.

---

## 4-5. 검색 예외 처리

다음 상황에서는 예외 정책을 적용한다.

| 상황 | 처리 방식 |
| --- | --- |
| 검색 결과 없음 | 추천 충전소 제공 |
| 검색 API 오류 | 오류 메시지 표시 |
| 서버 장애 | 기본 목록 제공 |
| 네트워크 오류 | 재시도 안내 |
| 위치 정보 없음 | 지역 검색 안내 |

예외 상황 발생 이력은 운영 로그에 저장한다.

---

## 4-6. 검색 운영 KPI

검색 운영 상태를 지속적으로 관리하기 위해 다음 KPI를 운영한다.

| KPI | 목표 |
| --- | --- |
| 검색 성공률 | 99% 이상 |
| 평균 응답시간 | 운영 기준 이내 |
| 검색 CTR | 전월 대비 증가 |
| 검색 실패율 | 지속 감소 |
| 검색 API 성공률 | 99.9% 이상 |

KPI는 운영 대시보드에서 일 단위 및 월 단위로 확인한다.

# 05. 통화 요약 검색

## 5-1. 기능 개요

통화 요약 검색은 저장된 통화 요약 내용을 키워드 기반으로 조회할 수 있는 기능이다.

검색 기능은 사용자가 필요한 통화 내용을 빠르게 확인할 수 있도록 지원하며, 검색 이력은 사용자 계정 단위로 관리한다.

---

## 5-2. 검색어 입력

사용자는 검색창에 키워드를 입력하여 원하는 통화 요약 내용을 검색할 수 있다.

검색창은 최근 검색어를 함께 제공하며, 사용자는 직접 입력하거나 최근 검색어를 선택하여 검색을 요청할 수 있다.

---

## 5-3. 검색 결과 제공

검색 결과는 최신순으로 정렬하여 사용자에게 제공한다.

검색 결과 화면에는 통화 제목, 통화 일시, 요약 내용 일부를 함께 표시하며, 사용자는 원하는 결과를 선택하여 상세 내용을 확인할 수 있다.

---

## 5-4. 검색 이력 관리

최근 검색어는 사용자 계정 기준으로 관리한다.

최근 검색어는 최대 20건까지 저장하며, 사용자는 개별 삭제 또는 전체 삭제를 수행할 수 있다.

로그아웃 시에도 최근 검색어는 계정에 저장된 정보를 기준으로 유지한다.

---

## 5-5. 검색 결과 화면

검색 결과 화면에서는 다음 정보를 제공한다.

| 항목 | 제공 여부 |
| --- | --- |
| 통화 제목 | O |
| 통화 일시 | O |
| 요약 내용 | O |
| 검색 키워드 강조 | O |
| 즐겨찾기 여부 | O |

검색 결과는 화면 스크롤 시 추가 결과를 순차적으로 제공한다.

---

## 5-6. 검색 로그 관리

통화 요약 검색 기능은 다음 정보를 운영 로그로 저장한다.

- 사용자 ID
- 검색 키워드
- 검색 시각
- 검색 결과 수
- 결과 선택 여부
- 검색 수행 화면

수집된 로그는 검색 품질 개선 및 운영 분석에 활용한다.

---

# 06. 운영 관리 정책

## 6-1. 운영 모니터링

운영자는 다음 항목을 실시간으로 확인한다.

- 검색 성공률
- 검색 실패율
- 평균 검색 응답시간
- API 오류율
- 서버 상태
- 검색 이용 건수

기준치를 초과하는 이상 징후가 발생하면 운영 알림을 생성한다.

---

## 6-2. 장애 대응

검색 서비스 장애 발생 시 다음 절차를 따른다.

1. 장애 감지
2. 운영 알림 발송
3. 원인 분석
4. 임시 운영 정책 적용
5. 서비스 복구
6. 장애 보고서 작성

복구 이후에는 장애 기간 동안의 운영 데이터를 분석하여 재발 방지 대책을 수립한다.

---

## 6-3. 로그 보관 정책

검색 로그는 운영 정책에 따라 안전하게 보관한다.

로그에는 개인정보를 직접 저장하지 않으며, 분석용 식별자를 활용한다.

로그 보관 기간 종료 후에는 내부 정책에 따라 안전하게 삭제한다.

---

## 6-4. 운영 보고 체계

검색 운영 현황은 주간 및 월간 단위로 보고한다.

보고 항목은 다음을 포함한다.

- 검색 이용 현황
- 주요 KPI
- 검색 품질 변화
- 장애 발생 현황
- 개선 과제
- 차기 운영 계획

---

## 6-5. 운영 권한 관리

| 권한 | 조회 | 수정 | 배포 |
| --- | --- | --- | --- |
| 일반 운영자 | O | X | X |
| 서비스 운영자 | O | O | X |
| 관리자 | O | O | O |

운영 정책 변경 이력은 감사 로그에 기록하며, 변경 내역은 운영 정책에 따라 관리한다.
