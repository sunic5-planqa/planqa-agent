# DOC-038: 사내 카페테리아 주문 시스템 PRD
**버전**: v1.0
**작성일**: 2024-03-26
**작성자**: 플랫폼기획팀
**상태**: 개발 중

## 1. 프로덕트 목적

사내 카페테리아 메뉴를 모바일로 사전 주문/결제할 수 있게 하여 점심시간 대기열을 줄인다.

## 2. 요구사항

점심시간 혼잡을 실질적으로 완화하기 위해, **주문 마감 시간을 이용 희망 시각 5분 전까지**로 설정하여 직원들이 최대한 유연하게 주문할 수 있도록 한다.

## 3. 정책

### 3-1. 주문 마감 정책

모든 주문은 **이용 희망 시각 최소 30분 전까지** 완료되어야 하며, 이후에는 주방 준비 시간 확보를 위해 주문이 마감된다.

## 4. 기능 상세

### 4-1. 메뉴 조회 및 주문

직원은 당일 메뉴를 조회하고 원하는 시간대를 선택하여 주문할 수 있다. 시스템은 현재 시각이 이용 희망 시각 30분 전을 초과한 경우 주문 버튼을 비활성화하고 결제 트랜잭션을 차단한다.

### 4-2. 결제

사내 복지포인트 또는 카드 결제를 지원한다.

## 5. 마일스톤

| 우선순위 | 기능 |
|--------|------|
| P0 | 메뉴 조회 및 주문 |
| P0 | 결제 |
| P1 | 주문 취소/변경 |
