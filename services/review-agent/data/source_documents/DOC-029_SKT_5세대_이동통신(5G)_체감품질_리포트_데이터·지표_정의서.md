## 1. 문서 목적
본 문서는 5세대 이동통신 체감품질 리포트에서 사용하는 데이터 항목, 지표 산식, 집계 주기, 품질 기준을 정의한다. 운영 조직과 네트워크 품질 조직은 동일한 정의를 사용하여 지역별 품질 변화와 개선 결과를 확인한다.

## 2. 측정 범위

### 2-1. 측정 대상
- SKT 5세대 이동통신 스마트폰 회선의 데이터 접속 시도
- 국내 기지국에서 발생한 내려받기·올리기 전송 기록
- 고객 단말에서 수집 동의가 완료된 체감 응답 기록

### 2-2. 제외 대상
- 시험 회선과 사내 검증 회선
- 해외 로밍 상태의 접속 기록
- 단말 시간이 서버 시간과 10분 이상 차이 나는 기록
- 원천 데이터 필수값이 누락된 기록

### 2-3. 집계 시간 기준
모든 날짜와 시간은 한국 표준시를 기준으로 한다. 일간 집계는 전일 00:00:00부터 23:59:59까지 발생한 기록을 대상으로 하며, 월간 집계는 해당 월의 첫날부터 마지막 날까지의 일간 확정값을 사용한다.

## 3. 데이터 원천과 처리 대상

### 3-1. 원천 데이터
| 데이터 항목 | 설명 | 생성 주기 | 필수값 |
|---|---|---|---|
| 접속 시도 기록 | 데이터 세션 시작 요청 시각과 결과 | 실시간 | 회선 식별값, 기지국, 결과 코드 |
| 전송 품질 기록 | 전송량, 전송 시간, 재전송 횟수 | 5분 | 회선 식별값, 지역, 전송량 |
| 체감 응답 기록 | 고객 단말에서 측정한 첫 응답 소요 시간 | 세션 종료 시 | 회선 식별값, 측정 시각, 소요 시간 |
| 기지국 상태 기록 | 기지국 운영 상태와 장애 구간 | 1분 | 기지국, 상태, 시작 시각 |

### 3-2. 처리 시스템
원천 데이터는 내부 시스템인 분석 플랫폼에서 조회한다.

데이터 처리 담당자는 매일 06:00에 전일 원천 데이터의 적재 완료 여부를 확인하고, 06:30까지 필수값 누락률과 중복률을 점검한다. 필수값 누락률이 2%를 초과하거나 중복률이 1%를 초과하면 일간 집계를 보류하고 원천 데이터 담당자에게 재적재를 요청한다.

## 4. 지표 정의

| 지표명 | 정의 | 산식 | 단위 |
|---|---|---|---|
| 접속 성공률 | 데이터 접속 시도 중 정상 연결된 비율 | 정상 연결 건수 ÷ 전체 접속 시도 건수 × 100 | 퍼센트 |
| 첫 응답 중앙값 | 체감 응답 기록을 오름차순으로 정렬했을 때 중앙에 위치한 값 | 유효 기록의 중앙값 | 밀리초 |
| 지역 가용률 | 지역별 측정 시간 중 정상 서비스 상태였던 비율 | 정상 상태 시간 ÷ 전체 측정 시간 × 100 | 퍼센트 |
| 재전송 비율 | 전체 전송 블록 중 재전송된 블록의 비율 | 재전송 블록 수 ÷ 전체 전송 블록 수 × 100 | 퍼센트 |
| 품질 개선 지역 수 | 전월 대비 접속 성공률이 1퍼센트포인트 이상 높아지고 첫 응답 중앙값이 5% 이상 감소한 지역 수 | 조건 충족 지역 개수 | 개 |

### 4-1. 지역 집계 단위
지역은 시·군·구 행정구역 코드를 기준으로 집계한다. 하나의 측정 기록이 둘 이상의 지역에 걸치지 않도록 접속 시작 시점의 기지국 위치를 기준 지역으로 사용한다.

### 4-2. 유효 기록 기준
- 접속 시도 기록은 결과 코드가 정상 또는 실패로 명시된 건만 사용한다.
- 첫 응답 소요 시간은 0밀리초 초과 30,000밀리초 이하의 값만 사용한다.
- 전송량이 0바이트인 기록은 전송 품질 지표에서 제외한다.
- 동일한 회선 식별값, 측정 시각, 기지국을 가진 중복 기록은 최초 적재 건만 사용한다.

## 5. 집계 처리

### 5-1. 원천 데이터 검증
**목적**: 불완전하거나 중복된 원천 데이터가 일간 지표에 반영되는 것을 방지한다.

**조건**: 전일 원천 데이터가 06:00까지 적재 완료 상태여야 한다.

**동작**: 데이터 처리 담당자는 필수값 누락률, 중복률, 시간 범위를 검사하고 기준을 초과한 데이터 묶음을 격리한다.

**결과**: 검증을 통과한 데이터 묶음에는 사용 가능 상태를 부여하고, 격리 건은 원천 데이터 담당자에게 전달한다.

**예외**: 원천 데이터가 07:00까지 재적재되지 않으면 해당 일자의 지표를 미확정 상태로 표시한다.

### 5-2. 일일 리포트 생성
**목적**: 전일 네트워크 체감품질을 오전 운영 회의 전에 제공한다.

**결과**: 매일 08:00까지 지역별 지표를 운영 화면에 게시하고 전일 대비 변화가 큰 상위 10개 지역을 함께 표시한다.

**조건**: 전일 원천 데이터의 98% 이상이 06:30까지 적재되고 5-1의 검증을 통과해야 한다.

**동작**: 집계 작업은 유효 기록을 지역별로 분류하고, 4장의 산식에 따라 접속 성공률·첫 응답 중앙값·지역 가용률·재전송 비율을 계산한다.

**예외**: 기준 적재율을 충족하지 못하면 전일 확정값을 게시하지 않고 미확정 사유와 예상 복구 시각을 표시한다.

### 5-3. 월간 확정 처리
**목적**: 월간 품질 추세와 개선 지역을 동일한 기준으로 비교한다.

**조건**: 해당 월의 모든 일간 지표가 확정 상태여야 한다.

**동작**: 데이터 처리 담당자는 일간 지표를 월 단위로 통합하고 누락 일자와 재처리 이력을 확인한다.

**결과**: 다음 달 3영업일 12:00까지 월간 지표를 확정하고 변경 이력을 저장한다.

**예외**: 미확정 일간 지표가 남아 있으면 월간 확정을 보류하고 보류 대상 일자를 표시한다.

## 6. 데이터 품질 기준
| 점검 항목 | 정상 기준 | 처리 방식 |
|---|---|---|
| 필수값 누락률 | 2% 이하 | 초과 시 일간 집계 보류 |
| 중복률 | 1% 이하 | 중복 제거 후 비율 기록 |
| 시간 범위 오류율 | 0.5% 이하 | 오류 기록 격리 |
| 지역 코드 미매핑률 | 0.2% 이하 | 미매핑 목록 별도 보고 |

## 7. 보관과 접근
- 원천 식별값은 일간 지표 확정 후 30일 동안 보관한 뒤 비식별값으로 대체한다.
- 일간·월간 지표와 변경 이력은 36개월 동안 보관한다.
- 원천 데이터는 데이터 처리 담당자와 품질 분석 담당자만 조회할 수 있다.
- 운영 화면에서는 지역별 집계값만 제공하고 개별 회선 기록은 표시하지 않는다.

## 8. 변경 관리
지표 정의, 산식, 제외 기준을 변경할 경우 변경 이유, 적용일, 영향받는 과거 지표 범위를 기록한다. 산식 변경은 월간 지표 확정일 다음 날부터 적용하며, 과거 수치를 다시 계산하는 경우 재계산 대상 기간과 이전 값을 함께 보관한다.
