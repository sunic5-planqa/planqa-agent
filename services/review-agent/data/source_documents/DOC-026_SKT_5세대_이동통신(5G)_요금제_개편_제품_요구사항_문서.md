## 1. 개편 배경

### 1-1. 문제 정의
2026년 1분기 신규 가입 상담 12,400건을 분석한 결과, 월 4만 원에서 6만 원 사이의 요금제를 문의한 고객 비중은 48%였고, 동일 가격 구간에서 데이터 제공량 차이를 이해하기 어렵다는 문의가 월평균 820건 발생했다. 또한 가입 후 30일 이내 요금제를 다시 변경한 고객 중 61%가 최초 선택 시 데이터 사용량을 정확히 예측하기 어려웠다고 응답했다.

### 1-2. 해결 방향
중간 가격대의 데이터 구간을 세분화하고, 각 요금제의 핵심 혜택을 한 문장으로 비교할 수 있도록 요금제 구조를 개편한다. 개편 요금제는 고객의 최근 3개월 데이터 사용량을 기준으로 추천하되, 고객이 추천 결과를 확인한 후 직접 요금제를 선택하도록 한다.

## 2. 목표와 범위

### 2-1. 목표
- 월 4만 원에서 6만 원 사이 요금제의 선택 비율을 출시 후 3개월 안에 35% 이상으로 높인다.
- 가입 후 30일 이내 요금제 재변경률을 기존 14%에서 9% 이하로 낮춘다.
- 요금제 비교 화면에서 가입 완료까지의 평균 소요 시간을 6분 이내로 유지한다.

### 2-2. 포함 범위
- 개인 명의 스마트폰 회선의 신규 가입 및 요금제 변경
- 데이터 제공량, 월정액, 공유 가능 데이터, 로밍 혜택 비교
- 고객 사용량 기반 요금제 추천

### 2-3. 제외 범위
- 법인 회선과 사물인터넷 회선
- 단말기 할부 및 선택약정 할인 정책 변경
- 기존 부가서비스의 과금 구조 변경

## 3. 성과 지표와 측정 방식

### 3-1. 핵심 성과 지표
| 지표 | 산식 | 측정 주기 | 목표 |
|---|---|---|---|
| 중간 가격대 선택 비율 | 해당 구간 가입 건수 ÷ 전체 신규·변경 가입 건수 × 100 | 주간 | 35% 이상 |
| 30일 이내 재변경률 | 가입 후 30일 이내 재변경 회선 수 ÷ 전체 가입 회선 수 × 100 | 월간 | 9% 이하 |
| 가입 완료 평균 소요 시간 | 요금제 비교 화면 진입부터 가입 완료까지의 소요 시간 평균 | 주간 | 6분 이내 |

### 3-2. 보조 관찰 지표
- 추천 요금제 선택률은 추천 결과를 확인한 고객 중 추천 요금제를 선택한 비율로 계산한다.
- 요금제별 MRC를 월 단위로 산출하고, 개편 전 3개월 평균 대비 변화를 비교한다.
- 측정 로그가 누락된 가입 건은 성과 지표 산정 대상에서 제외하고 누락률을 별도로 보고한다.

## 4. 요금제 구성

| 요금제 | 월정액 | 기본 데이터 | 공유 가능 데이터 | 주요 대상 |
|---|---:|---:|---:|---|
| 슬림 12 | 39,000원 | 12기가바이트 | 2기가바이트 | 월 사용량이 적은 고객 |
| 밸런스 45 | 49,000원 | 45기가바이트 | 8기가바이트 | 영상과 사회관계망 이용이 잦은 고객 |
| 밸런스 90 | 59,000원 | 90기가바이트 | 15기가바이트 | 고화질 영상 이용이 잦은 고객 |
| 맥스 | 79,000원 | 무제한 | 30기가바이트 | 대용량 이용 고객 |

모든 요금제는 국내 음성 통화와 문자 메시지를 기본 제공한다. 기본 데이터 소진 후에는 슬림 12는 초당 1메가비트, 밸런스 45와 밸런스 90은 초당 3메가비트 속도로 데이터를 계속 사용할 수 있으며, 맥스는 별도 속도 제한을 두지 않는다.

## 5. 상세 요구사항

### 5-1. 요금제 변경
**목적**: 고객이 현재 사용량과 다음 달 예상 사용량을 확인한 뒤 적합한 요금제를 선택하도록 한다.

**조건**: 개인 명의 정상 회선이며 미납, 이용 정지 또는 명의 변경 진행 상태가 아니어야 한다.

**동작**: 고객은 T월드 앱에서 최근 3개월 평균 사용량과 추천 요금제를 확인하고, 변경할 요금제를 선택한 뒤 본인 인증을 완료한다.

**결과**: 매월 1일부터 25일까지 신청한 변경은 다음 달 1일에 적용되고, 26일부터 말일까지 신청한 변경은 다다음 달 1일에 적용된다. 적용 예정일과 예상 월정액을 신청 완료 화면에 표시한다.

**예외**: 적용 예정일 전에 회선이 해지되거나 명의가 변경되면 신청을 자동 취소하고 고객에게 문자 메시지를 발송한다.

### 5-2. 청년 데이터 보너스
**목적**: 데이터 사용량이 빠르게 증가하는 청년 고객에게 추가 데이터 혜택을 제공한다.

**조건**: 신청일 기준 만 19세 이상 34세 이하의 개인 고객이며 밸런스 45 또는 밸런스 90을 이용해야 한다.

**동작**: 조건을 충족한 고객에게 매월 1일 추가 데이터 10기가바이트를 제공한다.

**결과**: 추가 데이터 잔여량을 기본 데이터와 구분하여 표시하고, 추가 데이터가 먼저 소진되도록 한다.

**예외**: 고객이 대상 요금제를 해지하거나 만 35세가 되는 달의 다음 달부터 추가 데이터 제공을 종료한다.

### 5-3. 가족 데이터 나눔
**목적**: 가족 결합 회선 사이에서 사용하지 않은 데이터를 효율적으로 활용하도록 한다.

**조건**: 동일한 가족 결합 그룹에 등록된 정상 회선이며, 데이터를 보내는 회선에 공유 가능 데이터가 1기가바이트 이상 남아 있어야 한다.

**동작**: 고객은 월 2회까지 1기가바이트 단위로 데이터를 보낼 수 있으며, 1회 최대 전송량은 5기가바이트다.

**결과**: 전송 완료 즉시 받는 회선의 공유 데이터 잔여량에 반영하고, 두 고객에게 처리 결과를 알린다.

**예외**: 받는 회선이 해지, 이용 정지 또는 해외 로밍 중이면 전송을 차단하고 사유를 안내한다.

### 5-4. 로밍 데이터 추가 혜택
**목적**: 해외 체류 중 예상하지 못한 데이터 비용을 줄인다.

**조건**: 밸런스 90 또는 맥스 이용 고객이 출국 전에 로밍 사용 동의를 완료해야 한다.

**동작**: 출국일 기준 30일 안에 사용할 수 있는 로밍 데이터 3기가바이트를 회선에 부여한다.

**결과**: 로밍 데이터가 소진되면 국내 기본 데이터와 분리하여 사용 중단 안내를 제공한다.

**예외**: 로밍 데이터 사용 동의를 철회하면 미사용 잔여량을 즉시 소멸시키고 철회 완료 사실을 안내한다.

### 5-5. 청년 데이터 보너스 신청 절차
**목적**: 청년 데이터 보너스 대상 고객이 본인 자격을 확인하고 혜택을 신청하도록 한다.

**조건**: 고객이 5-2의 연령 및 요금제 조건을 충족하고, 동일 회선에 청년 데이터 보너스가 적용되어 있지 않아야 한다.

**동작**: 고객은 T월드 앱의 혜택 관리 화면에서 생년월일 확인에 동의하고 신청 버튼을 선택한다.

**결과**: 자격 확인이 완료되면 다음 달 1일부터 혜택을 적용하고 적용 예정일을 신청 완료 화면에 표시한다.

**예외**: 자격 확인에 실패하면 신청을 저장하지 않고 실패 사유와 고객센터 문의 방법을 안내한다.

## 6. 운영 정책
- 요금제 변경 이력과 혜택 신청 이력은 고객별로 24개월 동안 보관한다.
- 상담원은 고객 동의를 받은 경우에만 요금제 변경 신청을 대행할 수 있다.
- 시스템 점검 시간은 매월 둘째 주 수요일 02:00부터 04:00까지이며, 해당 시간에는 변경 신청을 받지 않는다.
- 가격, 데이터 제공량 또는 적용일을 변경할 경우 시행일 30일 전에 고객에게 고지한다.

## 8. 검수 기준
- 조건에 맞지 않는 회선에서는 요금제 변경과 혜택 신청이 차단되어야 한다.
- 신청 완료 화면의 월정액, 적용 예정일, 데이터 제공량이 선택한 요금제 정보와 일치해야 한다.
- 가족 데이터 나눔의 전송량과 월별 횟수 제한이 모든 진입 경로에서 동일하게 적용되어야 한다.
- 각 예외 상황에서 신청 상태, 고객 안내 문구, 이력 저장 결과를 확인할 수 있어야 한다.
