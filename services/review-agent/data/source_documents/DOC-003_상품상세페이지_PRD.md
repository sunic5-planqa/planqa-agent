**버전**: v1.0
**작성일**: 2024-01-10
**작성자**: 서비스기획팀
**상태**: 확정

---

## 1. 프로덕트 목적

### a. 문제 정의

현재 NxEF는 인스타그램 DM을 통해 상품 문의와 구매를 처리하고 있다. 이 방식은 고객이 상품의 실제 상태를 정확히 파악하기 어렵고, 운영자 또한 동일한 문의를 반복 응대해야 하는 비효율이 발생한다. 특히 중고 명품/패션 상품의 특성상 컨디션에 대한 기준이 고객과 판매자 사이에 달라 분쟁이 발생하는 경우가 잦다.

상품 상세 페이지(PDP)는 고객이 구매 결정을 내리는 핵심 공간으로, 상품 상태를 명확하게 전달하고 불필요한 문의를 줄이는 것을 목적으로 한다.

### b. 제안

상품의 컨디션을 등급 체계(S/A/B/C)로 표준화하고, 구성품 여부, 사이즈(스니커즈), 실착 여부 등을 구조화된 형태로 표현한다. 이를 통해 구매 결정에 필요한 정보를 PDP 한 페이지에서 완결적으로 제공한다.

---

## 2. 성공 지표

- **PDP → 장바구니 전환율 15% 이상**
  - 근거: 일반 패션 이커머스 PDP → 장바구니 전환율 약 10~20%. 중고 특성상 상품 설명 신뢰도가 전환에 크게 영향을 미치므로 15%를 목표로 설정.
- **상품 문의(채널톡) 건수 월 100건 이하 유지**
  - 근거: PDP에서 필요한 정보를 충분히 제공하면 단순 컨디션/구성품 문의가 감소할 것으로 예상.

---

## 3. 기술적 제약

- 카페24 PDP 템플릿 기반으로 레이아웃 커스터마이징에 한계 존재
- 상품 사진 업로드는 최대 20장까지 가능 (카페24 제한)
- 360도 뷰어, AR 기능 구현 불가

## 4. 상품 컨디션 등급 기준

NxEF는 중고 상품의 상태를 고객에게 명확하게 전달하기 위해 아래 4단계 컨디션 등급을 사용한다. 모든 상품은 입고 시 이 기준에 따라 등급을 부여받는다.

| 등급 | 명칭 | 기준 |
|------|------|------|
| S | Mint | 미사용 또는 1~2회 착용. 태그, 더스트백 등 구성품 완전 포함. 외관상 사용 흔적 없음. |
| A | Excellent | **약간의 사용감**이 있으나 전반적으로 깨끗한 상태. 구성품 일부 포함. |
| B | Good | **적당한 사용감**이 있는 상태. 미세한 스크래치나 가죽 변색이 있을 수 있음. |
| C | Fair | **상당한 사용감**이 있는 상태. 스크래치, 오염 등이 있으나 기능적 문제는 없음. |

등급 판별은 입고 담당자가 실물 검수를 통해 진행하며, 경계 사례(예: A와 B 사이)의 경우 보수적으로 판단하여 **객관적 기준에 따라 적절히** 낮은 등급을 부여한다.

## 5. 기능 상세

### 5-1. 상품 사진 영역

- 메인 사진 1장 + 서브 사진 최대 19장 구성
- 스와이프로 사진 탐색 가능 (모바일)
- 필수 촬영 컷: 전면, 후면, 측면, 바닥, 로고/태그 클로즈업, 하자 부위 클로즈업(있는 경우)

### 5-2. 상품 정보 영역

상품 카드에 포함되는 정보:

| 항목 | 표시 방식 | 비고 |
|------|---------|------|
| 브랜드명 | 텍스트 | 예: FREITAG, Nike |
| 상품명(한글) | 텍스트 | 예: 프라이탁 F11 라씨 |
| 상품명(영문) | 텍스트 (보조) | 예: FREITAG F11 LASSIE |
| 컨디션 등급 | 태그 (S/A/B/C) | 색상 구분 |
| 판매가 | 굵은 텍스트 | |
| 사이즈 | 텍스트 | 스니커즈 카테고리 한정 |
| 구성품 | 체크리스트 | 박스, 더스트백, 태그 등 |
| 자체상품코드 | 소형 텍스트 | 예: NxEF-20397 |

### 5-3. 컨디션 상세 설명

- 등급 태그 아래 운영자가 직접 작성한 컨디션 상세 설명 노출
- 예시: "전체적으로 깔끔한 상태이며, 내부 패브릭에 미세한 보풀이 있습니다."
- 하자 사진이 있는 경우 "하자 상세 보기" 버튼으로 해당 사진으로 이동

### 5-4. 구매 액션 영역

- 장바구니 담기 버튼 (Primary)
- 바로 구매하기 버튼 (Secondary)
- 입고 알림 신청 버튼 (품절 상품 한정)

### 5-5. 유사 상품 추천

- 동일 카테고리의 다른 상품 최대 4개 노출 (현재 재고 있는 상품만)
- 동일 모델의 다른 재고가 있는 경우, 유사 상품 최상단에 표시
