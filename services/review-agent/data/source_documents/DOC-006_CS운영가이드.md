## 2. 문의 유형별 처리 기준

### 2-1. 상품 문의 (컨디션, 구성품 등)

- PDP 상세 설명 및 사진을 참고하여 1차 안내
- PDP에서 확인할 수 없는 추가 사진 요청 시: 해당 상품 담당자에게 사진 요청 후 **빠른 시일 내** 고객에게 전달
- 재고 소진 여부 확인 후 입고 알림 신청 안내

### 2-2. 배송 문의

- 운송장 번호 안내 (알림톡 미수신 고객에게 채팅으로 직접 제공)
- 배송 지연 시: 택배사 고객센터 연락 안내 및 **신속하게** 내부 상황 파악 후 안내
- 분실/파손 의심 시: **즉시** 사진 첨부 요청 후 팀장에게 보고

### 2-3. 반품/교환 문의

처리 기준은 반품/교환 정책서(DOC-005) 참고.

- 반품 승인 여부는 **가능한 한 빨리** 고객에게 안내
- 하자 반품의 경우: 사진 첨부 요청 → 검토 후 **적절한 조치** 안내
- 단순 변심 반품의 경우: 수령일 기준 7일 초과 시 정중히 거절

### 2-4. 결제/정산 문의

- 결제 오류: 결제 수단별 PG사 문의 안내 + 내부 확인 병행
- 환불 지연: 환불 처리 일시 확인 후 **최대한 빠르게** 안내
- 포인트 오지급: 어드민 확인 후 **당일 내** 정정 처리

## 3. 에스컬레이션 기준

아래 상황은 CS 담당자가 독자적으로 처리하지 않고 팀장 또는 관련 담당자에게 에스컬레이션한다.

- 고객이 법적 조치(소비자원 신고, 경찰 신고 등)를 언급하는 경우
- 단일 건 환불 금액이 50만원을 초과하는 경우
- 미디어, SNS 이슈화 가능성이 있는 경우
- CS 담당자가 처리 기준을 명확히 판단하기 어려운 경우

---

## 4. 고객 응대 톤앤매너

- 모든 응대는 존댓말 사용을 원칙으로 한다.
- 고객에게 내부 운영 상황(인력 부족, 시스템 오류 등)을 직접 노출하지 않는다.
- 처리가 불가한 요청이라도 "불가합니다"라는 단답식 응대 지양. 가능한 대안 또는 이유를 함께 안내한다.
- 고객이 흥분한 상태일 경우 감정 공감 후 해결 방안을 제시한다.

## 5. 자주 묻는 질문 (FAQ 업데이트 기준)

아래 유형의 문의가 주 3회 이상 반복될 경우, FAQ 페이지 업데이트를 기획팀에 요청한다.

- 동일 상품에 대한 반복적 사진 요청 → PDP 사진 보완 요청 검토
- 동일 정책에 대한 반복 문의 → FAQ 항목 신설 또는 PDP 내 고지 강화
