# NxEF 마이페이지 PRD
**버전**: v1.0
**작성일**: 2024-01-20
**작성자**: 서비스기획팀
**상태**: 개발 중

---

## 1. 프로덕트 목적

마이페이지는 고객이 자신의 주문, 포인트, 쿠폰, 등급 현황을 한곳에서 확인하고 관리하는 공간이다. 구매 이후의 고객 경험(주문 추적, 반품 신청, 후기 작성 등)을 지원하여 재구매까지 이어지는 고객 여정을 완성한다.

---

## 2. 마이페이지 구성

### 2-1. 상단 요약 카드

로그인 상태의 마이페이지 최상단에 아래 정보를 요약 표시:
- 회원 이름 + 등급 아이콘
- 보유 포인트 / 사용 가능 쿠폰 수 / 현재 진행 중인 주문 수

### 2-2. 주문 내역

**주문 목록**
- 주문 날짜, 상품 썸네일, 상품명, 결제금액, 주문 상태 표시
- 주문 상태: 결제 완료 / 배송 준비 중 / 배송 중 / 배송 완료 / 반품 진행 중 / 반품 완료 / 취소 완료

**주문 상세**
- 주문번호, 결제수단, 배송지, 운송장 번호 (발송 후 표시)
- 판매자 정보: NxEF (고정값)
- 배송 조회 바로가기 링크

**가능한 액션 (주문 상태별)**

| 주문 상태 | 가능한 액션 |
|---------|-----------|
| 결제 완료 | 주문 취소 (30분 이내) |
| 배송 준비 중 | — |
| 배송 중 | 배송 조회 |
| 배송 완료 | 반품 신청 / 후기 작성 |
| 반품 완료 | — |

### 2-3. 포인트 내역

- 현재 보유 포인트 표시
- 포인트 적립/사용 이력 (최근 6개월)
- 포인트 유효기간: 적립일로부터 1년

### 2-4. 쿠폰함

- 보유 쿠폰 목록 (유효 쿠폰 / 만료 쿠폰 탭 구분)
- 쿠폰명, 할인 내용, 유효 기간, 사용 조건 표시

### 2-5. 회원 등급 현황

- 현재 등급 및 등급 아이콘
- 누적 구매 금액
- 다음 등급까지 필요한 추가 구매 금액
- 등급별 혜택 안내 링크

### 2-6. 개인 정보 관리

- 이름, 휴대폰 번호 변경
- 비밀번호 변경 (자체 가입 회원 한정)
- 배송지 등록/수정/삭제

### 2-7. 기타

- 후기 작성 내역 (작성한 후기 목록)
- Draw 응모 내역 (응모 진행 중 / 당첨 / 미당첨)
- 위탁 판매 신청 내역
- 로그아웃 버튼
- 회원 탈퇴 (별도 확인 페이지)

---

## 3. 기술적 제약

- 카페24 기본 마이페이지 기능을 최대한 활용하되, 등급/포인트 기능은 카페24 제공 기능과 연동
- Draw 응모 내역, 위탁 판매 내역은 NxEF 자체 DB에서 조회하여 표시
