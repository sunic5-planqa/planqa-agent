## 1. 제안 배경

### 1-1. 문제 정의
SKT 고객 3,200명을 대상으로 야간 이동 경험을 조사한 결과, 밤 10시 이후 혼자 이동할 때 가족이나 지인에게 현재 위치를 반복해서 전송한 경험이 있다는 응답이 46%였다. 응답자 중 38%는 별도 위치 공유 앱을 설치하지 않고 기존 통신사 앱에서 간단히 경로를 공유하기를 원했다.

### 1-2. 해결 방향
T월드 앱에서 보호자를 등록하고, 정해진 시간 동안 이동 경로와 도착 상태를 공유하는 T 안심동행 기능을 제공한다. 사용자는 공유 시작 전 전송 정보와 종료 시점을 확인하며, 보호자는 별도 앱 설치 없이 문자 메시지의 보안 링크를 통해 위치를 확인한다.

## 2. 목표와 범위

### 2-1. 목표
- 공유 시작부터 보호자 확인 화면 진입까지의 평균 시간을 30초 이내로 유지한다.
- 위치 공유를 시작한 건 중 정상 종료 또는 도착 확인으로 끝난 비율을 95% 이상으로 유지한다.
- 위치 공유 중 고객센터 문의 비율을 전체 실행 건의 0.5% 이하로 유지한다.

### 2-2. 포함 범위
- 보호자 최대 3명 등록
- 실시간 이동 경로 공유
- 도착 예정 시간 설정과 도착 확인
- 공유 중단, 종료 시간 연장, 보호자 변경

### 2-3. 제외 범위
- 경찰·소방 기관 자동 신고
- 사고 여부 자동 판정
- 미성년자 보호자 인증 정책 변경

## 3. 기능 개요

### 3-1. 핵심 경로 공유 기능
핵심 기능명은 '안심 경로 공유'로 정의한다.

**목적**: 고객이 야간 이동 중 자신의 이동 경로를 지정한 보호자에게 안전하게 공유하도록 한다.

**조건**: 고객이 위치 정보 이용과 보호자 전송에 동의하고, 유효한 휴대전화 번호를 가진 보호자를 1명 이상 선택해야 한다.

**동작**: 사용자가 '귀가 경로 공유'를 시작하면 이동 경로와 도착 예정 시간을 지정한 보호자에게 전송한다.

**결과**: 보호자는 보안 링크에서 고객의 최근 위치, 이동 경로, 도착 예정 시간을 확인할 수 있다.

**예외**: 위치 정보 수신이 2분 이상 중단되면 고객과 보호자에게 수신 지연 사실을 알리고 마지막 수신 위치를 표시한다.

### 3-2. 도착 확인
**목적**: 고객의 이동이 정상적으로 끝났음을 보호자에게 알린다.

**조건**: 고객이 설정한 목적지 반경 100미터 안에 2분 이상 머물러야 한다.

**동작**: 시스템은 고객에게 도착 여부 확인 알림을 보내고, 고객이 도착 완료를 선택하면 공유를 종료한다.

**결과**: 보호자 화면에 도착 완료 시각을 표시하고 위치 정보 갱신을 중단한다.

**예외**: 고객이 5분 안에 응답하지 않으면 공유를 유지하고 보호자에게 확인 대기 상태를 알린다.

## 4. 사용자 흐름

1. 고객이 T월드 앱의 생활안심 메뉴에서 T 안심동행을 선택한다.
2. 고객이 보호자, 목적지, 도착 예정 시간, 공유 시간을 설정한다.
3. 고객이 전송 정보를 확인하고 공유 시작을 선택한다.
4. 보호자가 문자 메시지의 보안 링크를 열고 본인 확인을 완료한다.
5. 시스템이 고객 위치를 30초 간격으로 갱신한다.
6. 고객이 도착 완료를 선택하거나 공유 시간이 끝나면 공유를 종료한다.
7. 고객과 보호자에게 종료 사유와 종료 시각을 표시한다.

## 5. 상세 기능

### 5-1. 보호자 등록
**목적**: 고객이 경로를 전달할 보호자를 사전에 등록하도록 한다.

**조건**: 고객이 보호자 이름, 휴대전화 번호, 관계를 입력하고 정보 제공 동의를 완료해야 한다.

**동작**: 시스템은 휴대전화 번호 형식을 확인하고 보호자에게 등록 안내 문자 메시지를 보낸다.

**결과**: 보호자가 등록 안내를 확인하면 보호자 목록에 확인 완료 상태로 표시한다.

**예외**: 잘못된 번호이거나 24시간 안에 확인하지 않으면 등록을 완료하지 않고 재전송 방법을 안내한다.

### 5-2. 공유 시간 설정
**목적**: 고객이 필요한 시간 동안만 위치 정보를 공유하도록 한다.

**조건**: 고객이 30분부터 4시간 사이에서 30분 단위로 공유 시간을 선택해야 한다.

**동작**: 시스템은 선택한 시간과 현재 시각을 기준으로 공유 종료 시각을 계산한다.

**결과**: 공유 시작 전 확인 화면과 보호자 화면에 동일한 종료 시각을 표시한다.

**예외**: 종료 시각이 지나면 위치 정보 갱신을 중단하고 고객과 보호자에게 자동 종료 사실을 알린다.

### 5-3. 공유 중 설정 변경
**목적**: 공유 중 상황 변화에 맞춰 보호자 또는 종료 시간을 수정하도록 한다.

**조건**: 공유 상태가 진행 중이고, 고객이 본인 인증을 완료해야 한다.

**동작**: 사용자는 보호자 연락처를 수정하거나 공유 종료 시간을 연장할 수 있다. 이를 적용하면 보호자에게 변경 알림을 발송한다.

**결과**: 변경된 보호자와 종료 시간을 고객 화면과 보호자 화면에 즉시 반영한다.

**예외**: 이미 종료된 공유 건은 수정할 수 없으며 새로운 공유를 시작하도록 안내한다.

### 5-4. 수동 종료
**목적**: 고객이 필요할 때 위치 공유를 즉시 중단하도록 한다.

**조건**: 공유 상태가 진행 중이어야 한다.

**동작**: 고객이 공유 종료를 선택하고 종료 사유를 확인한다.

**결과**: 위치 정보 갱신을 중단하고 고객과 보호자에게 수동 종료 시각을 표시한다.

**예외**: 네트워크 연결이 끊긴 상태에서 종료를 요청하면 기기에 종료 요청을 저장하고 연결 복구 후 서버에 반영한다.

## 6. 정보 보호와 운영 정책
- 위치 정보는 공유 시작 시점부터 종료 시점까지 수집하며, 종료 후 24시간이 지나면 원본 좌표를 삭제한다.
- 보호자 보안 링크는 공유 종료 시점 또는 발송 후 6시간 중 먼저 도래하는 시점에 만료한다.
- 보호자는 고객이 허용한 현재 위치, 이동 경로, 도착 예정 시간만 확인할 수 있다.
- 고객은 앱의 이용 기록 화면에서 최근 30일 동안의 공유 시작·종료 시각과 보호자 목록을 확인할 수 있다.
