# NxEF 사진 후기 페이지 PRD
**버전**: v1.0
**작성일**: 2024-01-30
**작성자**: 서비스기획팀
**상태**: 검토 중

---

## 1. 프로덕트 목적

### a. 문제 정의

중고 명품/패션 상품을 온라인으로 구매할 때 고객의 가장 큰 불안 요소는 "실제로 받았을 때 설명과 다를 것"이라는 우려다. 특히 사진만으로 컨디션을 판단해야 하는 구매 특성상, 실제 구매자가 받은 상품에 대해 직접 남긴 후기는 신뢰도를 높이는 데 큰 역할을 한다.

현재 NxEF에는 구매 후기를 남기거나 볼 수 있는 공간이 없어, 잠재 구매자가 다른 구매자의 경험을 참고할 수 없는 상태다.

### b. 제안

구매 완료 고객이 사진 후기를 남길 수 있는 기능을 도입하고, 이를 별도의 후기 피드 페이지로 운영한다. 후기 페이지를 통해 브랜드 신뢰도를 높이고 잠재 고객의 구매 전환을 유도한다.

---

## 2. 성공 지표

- **구매 완료 고객의 후기 작성율 20% 이상**
- **후기 페이지 UV 월 5,000명 이상**
- **후기 페이지에서 PDP로의 전환율 15% 이상**
  - 근거: 후기를 보다가 구매 욕구가 생긴 고객이 해당 모델의 현재 재고 PDP로 이동하는 비율

---

## 3. 기술적 제약

- 카페24 기본 후기 기능 활용 가능하나, 별도 피드 페이지 구성은 커스터마이징 필요
- 동영상 후기(브이리뷰)는 외부 솔루션 연동 필요 (1차 범위 제외)

---

## 4. 기능 상세

### 4-1. 후기 작성 (고객)

- **작성 시점**: 배송 완료 알림톡 발송 7일 후 후기 작성 안내 알림톡 발송
- **작성 조건**: 해당 주문 구매 완료 + 상품 수령 확인 상태
- **작성 항목**:
  - 별점 (5점 만점)
  - 사진 첨부 (최소 1장, 최대 5장) — 사진 첨부 시 포인트 500원 지급
  - 텍스트 후기 (최소 20자 이상)
  - 실착 코디 태그 (선택): 착용자 키/체중 입력

### 4-2. 후기 피드 페이지

- 전체 후기를 최신순으로 나열하는 피드 형식
- 카테고리별 탭 필터 (전체 / 프라이탁 / 스니커즈 / 액세서리 / 지갑)
- 각 후기 카드에 노출 정보: 후기 사진, 상품명, 컨디션 등급, 별점, 첫 줄 텍스트
- 후기 카드 클릭 시 상세 후기 모달 또는 상세 페이지로 이동

### 4-3. PDP 내 후기 연동

- PDP 하단에 해당 상품과 동일한 **모델**의 후기가 있을 경우 최대 3개 미리보기 노출
- "전체 후기 보기" 링크 클릭 시 후기 피드 페이지(해당 모델 필터 적용 상태)로 이동

### 4-4. 품절 상품 후기 처리

중고 상품 특성상 후기를 남긴 상품 자체는 이미 판매 완료(품절)된 상태다. 품절 처리 후에도 해당 후기는 후기 피드 페이지에서 계속 노출된다. 단, 웹 전시에서 내린 상품(노출 OFF 처리)의 경우 해당 상품에 연결된 후기도 함께 비노출 처리된다.

후기 피드에서 후기 카드를 클릭하면 해당 모델의 **현재 재고 있는 PDP**로 이동한다. 현재 재고가 없는 경우 입고 알림 신청 페이지로 이동한다.
