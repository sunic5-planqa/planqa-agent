## 1. 프로덕트 목적

### a. 문제 정의

NxEF는 프라이탁, 스니커즈, 명품 액세서리, 명품 지갑 카테고리를 중심으로 운영되는 중고 패션 플랫폼이다. 현재 SNS(인스타그램, 카카오채널)를 통해 소수 고객에게 상품을 소개하고 있으나, 고객이 상품을 탐색하고 구매까지 이어지는 일관된 온라인 경험이 없는 상태다.

홈 화면은 고객이 NxEF에 첫 진입하는 지점으로, 브랜드 톤을 전달하고 구매 여정을 시작하게 하는 핵심 페이지다. 현재 카페24 기반 템플릿을 사용하고 있어 원하는 형태의 홈 화면 구성에 제약이 있으나, 가능한 범위 내에서 전환율에 유리한 구조를 설계한다.

### b. 제안

카페24 템플릿 기반의 모바일 웹 홈 화면을 구성하되, 상품 탐색 → PDP 진입 → 구매 전환 Funnel을 최적화하는 레이아웃을 설계한다. 홈 화면에서는 기획전 배너, 카테고리 진입, 신상품·추천 상품 노출을 핵심 기능으로 한다.

## 2. 경쟁 분석

| 서비스 | 홈 화면 핵심 요소 | 참고 포인트 |
|--------|----------------|-----------|
| 크림(KREAM) | 전체 화면 배너 + 드롭 상품 강조 | 한정 상품 희소성 강조 방식 |
| 번개장터 | 카테고리 퀵링크 + 실시간 거래 피드 | 탐색 편의성 |
| 당근마켓 | 동네 기반 피드 | 해당 없음 |
| 발란 | 브랜드 편집샵 스타일, 고급 이미지 강조 | 명품 톤앤매너 참고 |

NxEF는 고가 중고 상품 특성상 브랜드 신뢰감이 중요하므로, 발란의 톤을 참고하되 번개장터의 탐색 편의성을 결합하는 방향으로 설계한다.

## 3. 프로덕트 성공 지표와 비즈니스 목표

- **홈 UV (Unique Visitor) 월 2만명 달성**
  - 근거: 구매 전환율 1.5% 목표 달성을 위해 장바구니 유입 최소 1,000명 필요. 홈→장바구니 이탈율 95% 가정 시 월 2만명 유입 필요.
- **홈 → 상품 상세 진입율 30% 이상**
  - 근거: 현재 SNS에서 상품 소개 시 링크 클릭율 약 25%. 홈 화면 도입으로 5%p 이상 개선 목표.
- **신규 방문자 대비 회원가입 전환율 3% 이상**

## 4. 기술적 제약 사항

카페24 기반 웹으로 진행되는 만큼 아래 기술적 제약이 존재한다.

- 배너, 캐러셀 등 홈 화면 구성 요소는 카페24 기본 제공 위젯으로 제한됨
- **GA(Google Analytics) 직접 연동이 카페24 무료 플랜에서 불가**하여 별도 스크립트 삽입 검토 필요
- 카페24 자체 통계 툴은 제공되나 커스텀 이벤트 트래킹 불가
- 100% 반응형 템플릿 부재로 모바일 최적화에 한계 존재
- 외부 SDK(핵클 등) 삽입 가능 여부 별도 확인 필요

---

## 5. 고려되는 대안

- GA 직접 연동이 어려울 경우, 핵클 SDK를 통해 기본 Funnel 데이터를 수집하고 카페24 자체 통계를 보조 지표로 활용
- 모바일 최적화를 위해 PC보다 모바일 화면 우선 작업 후 PC 화면 대응

## 6. 프로덕트 기능

### 홈 화면 구성 요소

#### 6-1. 메인 배너 (캐러셀)
- 최대 5개 슬라이드로 구성, 관리자가 이미지·링크·노출 기간을 설정 가능
- 자동 슬라이드 간격: 3초
- 각 배너는 기획전 페이지 또는 특정 상품 PDP로 연결

#### 6-2. 카테고리 퀵링크
- 프라이탁 / 스니커즈 / 액세서리 / 지갑 4개 카테고리 아이콘 형태로 노출
- 탭 선택 시 해당 카테고리 검색 결과 페이지(SRP)로 이동

#### 6-3. 신규 입고 상품 섹션
- 최근 7일 이내 입고된 상품을 최대 8개까지 노출 (입고일 기준 최신순)
- 품절 상품은 자동 제외

#### 6-4. MD 추천 섹션
- 관리자가 직접 선별한 상품 최대 6개 노출
- 관리자가 순서 및 구성 상품을 수동으로 변경 가능

#### 6-5. 최근 본 상품 (로그인 회원 한정)
- 로그인 회원의 최근 조회 상품 최대 4개 노출
- 비로그인 상태에서는 해당 섹션 미노출

### 관리자 설정 기능
- 메인 배너 등록/수정/삭제/순서 변경
- MD 추천 상품 등록/수정/삭제
- 각 섹션 노출 여부 ON/OFF 설정
