# NxEF 회원가입 / 로그인 PRD
**버전**: v1.0
**작성일**: 2024-01-08
**작성자**: 서비스기획팀
**상태**: 확정

---

## 1. 프로덕트 목적

### a. 문제 정의

현재 NxEF는 별도의 회원 시스템 없이 카카오 채널을 통해 주문을 받고 있다. 이로 인해 고객 이력 관리, 주문 이력 조회, 포인트/쿠폰 관리 등의 기능이 불가능하며, 재구매 고객을 위한 맞춤 서비스를 제공할 수 없다.

### b. 제안

카페24 기본 회원 시스템을 활용하여 자체 회원가입 기능을 도입하고, 카카오·네이버 소셜 로그인을 추가하여 가입 허들을 낮춘다.

---

## 2. 성공 지표

- **방문자 → 회원가입 전환율 5% 이상**
- **소셜 로그인 비율 60% 이상** (카카오 + 네이버)
  - 근거: 모바일 환경에서 소셜 로그인이 직접 가입 대비 전환율이 높은 경향

---

## 3. 회원가입

### 3-1. 자체 회원가입

입력 항목:
- 이메일 (아이디로 사용)
- 비밀번호 (8자 이상, 영문+숫자 조합 필수)
- 이름
- 휴대폰 번호 (알림톡 수신 번호)
- 마케팅 수신 동의 (선택)

가입 완료 후:
- 신규 가입 쿠폰 자동 발급 (5,000원, 30일 유효)
- 웰컴 알림톡 발송

### 3-2. 소셜 로그인 (카카오/네이버)

- 카카오 또는 네이버 계정으로 소셜 로그인 시 최초 1회 추가 정보 입력 필요
  - 휴대폰 번호 (알림톡 수신용, 필수)
  - 마케팅 수신 동의 (선택)
- 소셜 로그인 가입 완료 후 신규 가입 쿠폰 동일 발급

---

## 4. 로그인

- 이메일 + 비밀번호로 자체 로그인
- 카카오 / 네이버 소셜 로그인 버튼 제공
- 비밀번호 찾기: 가입 이메일로 재설정 링크 발송
- 자동 로그인: 체크 시 30일간 로그인 상태 유지

---

## 5. 회원 정보 관리 (마이페이지)

- 이름, 휴대폰 번호, 비밀번호 변경 가능
- 배송지 등록/수정/삭제 (최대 5개, 기본 배송지 1개 설정)
- 마케팅 수신 동의 변경

---

## 6. 포인트 및 쿠폰 통합 관리

- 자체 회원가입 계정과 소셜 로그인 계정은 별도의 독립된 계정으로 운영된다.
- 동일인이 자체 회원가입과 카카오 소셜 로그인을 모두 진행한 경우 두 계정이 별도로 존재하며, 포인트/쿠폰/주문 이력은 각 계정에 귀속된다.
- 계정 통합 기능은 1차 범위에서 제외한다.
