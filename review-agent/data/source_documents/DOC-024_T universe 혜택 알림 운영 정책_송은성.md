# 01. 혜택 알림 운영 개요

## 1-1. 목적

본 문서는 T universe 혜택 알림 서비스의 운영 기준을 정의하고, 사용자에게 적절한 시점에 혜택 정보를 전달하기 위한 발송 정책과 메시지 운영 기준을 수립하는 것을 목적으로 한다.

혜택 알림은 사용자의 서비스 이용 이력 및 혜택 조건을 기반으로 개인화된 정보를 제공하며, 혜택 이용률 향상과 서비스 재방문을 지원한다.

---

## 1-2. 적용 범위

본 정책은 T universe에서 제공하는 모든 혜택 알림에 적용한다.

| 구분 | 적용 여부 |
| --- | --- |
| 쿠폰 발급 알림 | O |
| 쿠폰 만료 알림 | O |
| 제휴 혜택 알림 | O |
| 멤버십 혜택 알림 | O |
| 이벤트 참여 알림 | O |
| 신규 혜택 안내 | O |
| 맞춤형 혜택 추천 | O |

---

## 1-3. 운영 목표

혜택 알림 서비스는 다음 목표를 기반으로 운영한다.

- 사용자가 혜택을 놓치지 않도록 적시에 안내한다.
- 혜택 이용률을 지속적으로 향상시킨다.
- 불필요한 알림 발송을 최소화한다.
- 사용자 관심사에 맞는 혜택을 제공한다.
- 알림 품질을 지속적으로 개선한다.

---

## 1-4. 용어 정의

| 용어 | 정의 |
| --- | --- |
| 혜택 알림 | 사용자에게 제공되는 혜택 안내 메시지 |
| 발송 대상 | 알림을 수신하는 사용자 |
| 발송 실패 | 메시지가 정상 전달되지 않은 경우 |
| CTA | 혜택 상세 페이지로 이동하는 버튼 |
| 캠페인 | 동일 목적의 알림 발송 단위 |

---

## 1-5. 운영 지표

운영 상태는 다음 지표를 기준으로 관리한다.

| 지표 | 설명 |
| --- | --- |
| 발송 성공률 | 정상 발송 비율 |
| 오픈율 | 알림 확인 비율 |
| 클릭률(CTR) | CTA 클릭 비율 |
| 혜택 이용률 | 혜택 실제 사용 비율 |
| 발송 실패율 | 실패 건수 비율 |

---

## 1-6. 데이터 관리

혜택 알림 운영을 위해 다음 데이터를 활용한다.

- 회원 정보
- 마케팅 수신 동의 정보
- 혜택 보유 정보
- 쿠폰 사용 여부
- 서비스 이용 이력
- 알림 발송 이력

데이터는 운영 정책에 따라 안전하게 관리한다.

---

# 02. 혜택 대상 관리

## 2-1. 발송 대상 선정

혜택 알림은 혜택 제공 조건을 충족한 사용자에게 발송한다.

선정 기준은 다음과 같다.

- 혜택 보유 여부
- 이벤트 참여 여부
- 멤버십 가입 상태
- 서비스 이용 조건
- 마케팅 수신 설정

---

## 2-2. 대상 제외 기준

다음 사용자는 발송 대상에서 제외한다.

| 제외 조건 | 적용 |
| --- | --- |
| 마케팅 수신 거부 | O |
| 탈퇴 회원 | O |
| 휴면 회원 | 정책 적용 |
| 제재 계정 | O |
| 중복 발송 대상 | O |

동일 캠페인에서는 중복 발송을 허용하지 않는다.

---

## 2-3. 혜택 유형 관리

혜택은 다음 유형으로 구분하여 운영한다.

| 유형 | 예시 |
| --- | --- |
| 할인 쿠폰 | 금액 할인 |
| 제휴 할인 | 브랜드 혜택 |
| 적립 혜택 | 포인트 적립 |
| 이벤트 혜택 | 참여 리워드 |
| 멤버십 혜택 | 구독 혜택 |

혜택 유형별 운영 정책은 별도로 관리한다.

---

## 2-4. 우선순위 정책

동일 사용자에게 여러 혜택이 존재하는 경우 다음 순서를 적용한다.

1. 당일 만료 예정 혜택
2. 신규 지급 혜택
3. 이벤트 혜택
4. 일반 혜택

우선순위가 동일한 경우 발급일이 최근인 혜택을 우선한다.

---

## 2-5. 운영 로그

다음 정보를 운영 로그로 저장한다.

- 사용자 ID
- 캠페인 ID
- 혜택 ID
- 발송 예정 시각
- 발송 결과
- 클릭 여부

운영 로그는 성과 분석 및 품질 개선에 활용한다.

---

# 03. 혜택 알림 운영 기준

## 3-1. 발송 유형

혜택 알림은 다음 유형으로 운영한다.

| 유형 | 설명 |
| --- | --- |
| 즉시 발송 | 혜택 지급 직후 |
| 예약 발송 | 지정 시각 발송 |
| 조건 발송 | 특정 조건 충족 시 |
| 정기 발송 | 운영 일정 기준 |

---

## 3-2. 발송 채널

혜택 알림은 다음 채널을 지원한다.

- Push 알림
- 앱 내 메시지
- 문자 메시지(SMS)
- 카카오 알림톡
- 이메일

채널별 운영 기준은 서비스 정책에 따라 적용한다.

---

## 3-3. 발송 실패 처리

발송 실패 시 다음 정책을 적용한다.

| 상황 | 처리 방식 |
| --- | --- |
| Push 실패 | 앱 내 메시지 대체 |
| SMS 실패 | 재시도 |
| 알림톡 실패 | SMS 대체 |
| 이메일 실패 | 재발송 대상 등록 |

실패 이력은 운영 시스템에서 관리한다.

---

## 3-4. 운영 모니터링

운영자는 다음 항목을 실시간으로 확인한다.

- 발송 성공률
- 오픈율
- 클릭률
- 실패율
- 발송 건수
- 채널별 성공률

---

## 3-5. KPI

| KPI | 목표 |
| --- | --- |
| 발송 성공률 | 99% 이상 |
| 오픈율 | 전월 대비 증가 |
| 클릭률 | 전월 대비 증가 |

# 04. 알림 메시지 구성

## 4-1. 메시지 구성 요소

혜택 알림은 다음 요소로 구성한다.

- 제목
- 본문
- 혜택 정보
- CTA 버튼
- 발송 시각

사용자는 메시지를 통해 혜택 내용을 직관적으로 확인할 수 있어야 한다.

---

## 4-2. 메시지 작성 기준

혜택 알림은 **오전 9시부터 오후 8시까지만 발송**하며, 동일 사용자에게 동일 캠페인의 알림은 중복 발송하지 않는다. 또한 마케팅 수신 동의를 유지하는 사용자만 발송 대상으로 선정한다.

메시지 제목은 **20자 이내**로 작성하고, 본문은 핵심 혜택을 먼저 안내한다. CTA 버튼은 최대 1개만 포함하며, 문구는 사용자가 혜택 내용을 쉽게 이해할 수 있도록 간결한 표현을 사용한다.

---

## 4-3. CTA 구성

CTA는 혜택 상세 화면으로 연결하는 기능을 제공한다.

버튼 문구는 혜택 유형에 따라 운영하며, 동일 메시지에서는 하나의 CTA만 제공한다.

---

## 4-4. 메시지 검수

발송 전 다음 항목을 검수한다.

- 오탈자
- 혜택 정보 정확성
- 링크 정상 여부
- CTA 동작 여부
- 이미지 노출 여부

검수 완료 후 발송 대상에 포함한다.

---

# 05. 운영 관리 정책

## 5-1. 발송 이력 관리

혜택 알림 발송 이력은 사용자 단위로 관리한다.

다음 정보를 저장한다.

| 저장 항목 | 설명 |
| --- | --- |
| 사용자 ID | 발송 대상 사용자 |
| 캠페인 ID | 캠페인 식별자 |
| 혜택 ID | 혜택 식별자 |
| 발송 시각 | 실제 발송 시간 |
| 발송 채널 | Push, SMS 등 |
| 발송 결과 | 성공/실패 |

발송 이력은 동일 캠페인의 중복 발송 방지 및 운영 분석에 활용한다.

---

## 5-2. 발송 실패 처리

발송 실패가 발생한 경우 실패 유형에 따라 재처리를 수행한다.

| 실패 유형 | 처리 방식 |
| --- | --- |
| Push 발송 실패 | 앱 내 메시지 전환 |
| SMS 발송 실패 | 재발송 수행 |
| 알림톡 실패 | SMS 대체 발송 |
| 시스템 오류 | 운영자 확인 후 재처리 |
| 사용자 차단 | 재발송 제외 |

재발송 대상은 운영 정책에 따라 관리한다.

---

## 5-3. 운영 모니터링

운영자는 다음 항목을 실시간으로 모니터링한다.

- 발송 성공률
- 발송 실패율
- 채널별 성공률
- 오픈율
- CTR
- 혜택 이용률

운영 기준을 초과하는 이상 징후가 발생하면 운영 알림을 생성한다.

---

## 5-4. 운영 KPI

| KPI | 목표 |
| --- | --- |
| 발송 성공률 | 99.0% 이상 |
| Push 성공률 | 99.5% 이상 |
| SMS 성공률 | 99.9% 이상 |
| 오픈율 | 전월 대비 증가 |

KPI는 주간 및 월간 단위로 분석한다.

## 5-5. 운영 보고

운영 결과는 주간 및 월간 단위로 보고한다.

보고 항목은 다음을 포함한다.

# 07. 알림 발송 정책

## 7-1. 발송 대상 정책

혜택 알림은 다음 조건을 모두 만족하는 사용자에게 발송한다.

- 마케팅 정보 수신에 동의한 사용자
- 혜택 지급 또는 이용 조건을 충족한 사용자
- 발송 제한 대상이 아닌 사용자
- 정상 회원 상태를 유지하는 사용자

조건을 만족하지 않는 경우 알림을 발송하지 않는다.

---

## 7-2. 발송 시간 정책

혜택 알림은 운영 정책에서 정한 발송 가능 시간 내에만 발송한다.

예약 발송의 경우에도 동일한 발송 가능 시간을 적용하며, 발송 가능 시간을 벗어나는 경우 다음 발송 가능 시간으로 자동 조정한다.

---

## 7-3. 중복 발송 정책

동일 캠페인의 혜택 알림은 동일 사용자에게 중복 발송하지 않는다.

이미 동일 혜택을 안내한 경우에는 추가 발송을 제한하며, 새로운 혜택이 지급된 경우에만 신규 알림을 발송한다.

---

## 7-4. 채널 선택 정책

알림은 캠페인별 우선 채널을 기준으로 발송한다.

기본 채널 발송에 실패한 경우 대체 채널을 적용할 수 있으며, 사용자 수신 설정에 따라 지원 가능한 채널만 사용한다.

---

## 7-5. 예외 처리 정책

다음 경우에는 알림 발송을 제한한다.

| 상황 | 처리 방식 |
| --- | --- |
| 마케팅 수신 거부 | 발송 제외 |
| 탈퇴 회원 | 발송 제외 |
| 휴면 회원 | 정책에 따라 제한 |
