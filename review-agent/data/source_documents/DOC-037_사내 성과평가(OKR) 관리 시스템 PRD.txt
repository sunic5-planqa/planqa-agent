
# DOC-037: 사내 성과평가(OKR) 관리 시스템 PRD
**버전**: v1.0
**작성일**: 2024-03-25
**작성자**: 플랫폼기획팀
**상태**: 검토 중

## 1. 프로덕트 목적

분기별 OKR(목표 및 핵심 결과) 수립과 진척 관리를 시스템화하여, **목표 설정의 투명성을 높이고 팀 간 목표 정렬(Alignment)을 강화한다.**

## 2. 성공 지표

- **팀 OKR과 개인 OKR의 연결 비율 90% 이상**
- **분기별 OKR 리뷰 참여율 85% 이상**

## 3. 기능 상세

### 3-1. 개인 OKR 진척률 표시

직원은 본인이 설정한 핵심 결과(KR)별로 달성률을 %로 입력할 수 있으며, 입력된 수치는 진척 그래프로 시각화되어 표시된다.

### 3-2. KR 달성 현황 조회

팀장은 팀원별 핵심 결과(KR) 달성 정도를 대시보드에서 퍼센트 및 그래프 형태로 확인할 수 있다.

## 4. 마일스톤

| 우선순위 | 기능 |
|--------|------|
| P0 | 개인 OKR 작성 |
| P0 | 진척률 입력 및 조회 |
| P0 | OKR 히스토리 타임라인 애니메이션 효과 |
| P1 | 핵심 결과(KR) 수정 이력 관리 |
| P2 | 팀 OKR ↔ 개인 OKR 연결 기능 |
| P2 | 상위-하위 OKR 정렬도 시각화 |
